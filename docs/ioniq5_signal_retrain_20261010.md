# 추가 주행 수집 및 내부 ONNX 재학습 — 2026-10-10

사용자가 첫 비교 주행 이후의 차량 자료를 모두 가져와 다시 학습하도록 요청했다.
수집과 재학습을 완료했고 **새로운 전체 ONNX와 별도 비교용 ONNX를 실제로 생성했다.**
다만 이번 12가지 설정도 개발 검증을 통과하지 못했다. 녹색 진행 억제는 이전 후보보다
완화됐지만 적색 대기의 미래 속도가 함께 상승했다. 학교 앞 녹색 지연도 해결하지 못했다.
새 후보는 로컬 분석용으로 보관하며 차량의 제어 모델이나 비교 모델을 교체하지 않았다.

  `0000108f--bf5ec53e55--2`까지 수집했다. 마지막 구간은 기록 종료 후 복사했다.

  차량의 원본 파일은 변경하거나 삭제하지 않았다. 이후 새로 생기는 정차 녹화까지
  끝없이 추적하는 작업은 아니며 최초 목록을 수집 경계로 고정했다.
- 새로 이동한 주행은 `108d--6c4371c485`, `108e--a1bc7502db`다.
  D단을 포함한 49개 구간, 요약 로그 기준 실제 이동 약 34.64분이다.
  나머지 상당 부분은 같은 장소의 P단 대기다.
- 비교 기록은 **23,285개**, modelV2는 93,326개 중 93,325개 valid다.
  d/e/f 각 첫 구간에서 frame ID 누락 16/17/16개, f 첫 구간에서 invalid 1개가 있다.
  이 외 구간 내부 model frame ID 누락은 없고 각 구간 안에서 비교 drop 누계 증가는 없다.
  이 수치만으로 시작 시 누락의 원인을 확정하지 않는다.
- 개인 영상·원본 로그·특징·모델은
  `.analysis/archive/2026-10-10-signal-retrain/`에 로컬 보관한다.

## 영상 확인과 학습 자료

49개 D단 포함 구간의 5초 간격 도로 영상 모음을 만들고, 대기/전환 후보 장면의
원본 크기 영상으로 적용 신호와 주변 차량·보행자를 확인했다. 모든 프레임을 사람이
정답 표시한 것은 아니다. 신호 색과 전방 장애물을 구별해 다음 학습 목표를 사용했다.

| 목표 | 실제 사용 표본 | 의미 |
|---|---:|---|
| 적색 대기 | 829 | 네 번의 대기 사건. 정지했고 이후 10초도 적색인 구간의 x/v/a=0 |
| 녹색 출발 | 55 | 두 번의 직진 출발. 기록된 다음 10초 속도·가속도와 적분 거리 |
| 기존 출력 보존 | 1,118 | 다른 D단 주행에서 원본 모델의 출력을 유지하는 목표 |
| 합계 | **2,002** | 연속 프레임이므로 독립 사건 2,002개라는 뜻이 아님 |

녹색 목표는 `108d--15`의 51~57초, `108e--13`의 11~16초다. 두 경우 초기 전방에
정지한 선행차는 없지만 두 번째에는 인접 버스/차량이 함께 출발한다. 실제 운전 궤적을
모방한 목표이며 이상적이거나 안전성이 검증된 출발 궤적이라고 주장하지 않는다.
횡방향 회전이 큰 장면에 이동 거리 적분을 전방 x의 정답으로 강제하지 않았다.

기존 출력 보존 표본은 속도·기어·원본 예측 조건으로 골랐다. 원본의 정답 여부를
보증하는 표본은 아니며, 원본의 잘못된 예측을 보존할 가능성도 남는다.

새 두 주행의 50개 구간과 첫 주행의 7개 구간을 연속 20 Hz로 재생해
**57개 구간, 67,845개의 도로/광각 프레임 쌍**에서 특징을 추출했다.
새 두 주행은 전 구간을 재생하되 P단, 불확실한 전환, 정답 조건에 맞지 않는 프레임은
직접 학습 목표에서 제외했다. 이전 실험의 적색 29개만 다시 학습한 작업이 아니다.

## 학습 변경 범위와 자료 분리

원본 내부 모델 SHA256은
`f73a9e535523d5e9acb9e642c64e33d631825dc8ba74123757d107cedd047bb5`다.
영상·시간 특징을 만드는 층은 고정하고 마지막 plan 선형층의 **0.5초 이후 종방향
x/v/a 평균 75행**만 정규화된 ridge 최소제곱법으로 재학습했다.
0.5초 미만 출력, 횡방향, 다른 출력 헤드, 시간 이력 피드백과 불확실성은 보존했다.
불확실성을 새 평균에 맞춰 다시 보정한 것은 아니다.

- 학습: `108d--0..23`, `108e--0..13`의 조건 충족 표본.
- 개발/후보 선택: `108e--14..18`의 두 다른 대기·전환 사건과 주행 보존 표본.
- 선택 후 평가: `108e--19..25`, 기존 첫 주행 `108c--13..19`.
- 하나의 대기가 다음 구간으로 이어지면 같은 역할에 묶었다. 연속 프레임을 무작위로
  학습/검증 양쪽에 나누지 않았다. 단, 같은 차량·지역·날짜 자료이므로 일반 도로의
  독립 벤치마크로 볼 수는 없다. 첫 주행 영상은 이전 분석에서 이미 본 자료다.

정답 사건 가중치 0.1/0.3/1과 ridge 0.01/0.1/1/10의 12가지를 비교했다.
개발 검사에는 주행 보존, 녹색 진행 억제, 적색 오차, 음수 미래 속도 및 큰 적색
미래 속도를 함께 포함했다. 대기 시간이 긴 사건이 프레임 수만으로 학습을 지배하지
않도록 목표 그룹의 전체 가중치를 맞췄다. 적색/녹색은 별도 목표 그룹이다.

**12개 모두 실패했다.** 실패 항목 수와 보존 변화/적색 오차를 기준으로
`mass0.1_ridge10`을 진단용으로 보관했다. 통과한 후보로 선택한 것이 아니다.
모델·선택 결과를 저장한 뒤 별도 평가 자료의 후보 출력을 계산했으며 그 결과로
가중치나 설정을 다시 조정하지 않았다.

보관한 후보의 개발/별도 평가 적색 표본에서 v10<-0.1 또는 v10>5 m/s 표본은 0이다.

## ONNX 산출물과 무결성 검사

- 전체 후보: `internal_signal_balanced_candidate.onnx`, **60,792,584 bytes**.
  SHA256: `91d47a8970b09f27c244ad0deee85e4d043e94a1ed22db704c4c6dfea195f2c8`.
- 별도 비교 그래프: `policy_shadow_balanced.onnx`, **14,038,398 bytes**.
  SHA256: `6df631f661c2db531144c3c244711bcdcd3d061013b3071d3b65e168e197331b`.
- ONNX full checker 통과. 원본과 그래프 노드·입출력 형식이 같으며 변경 initializer는
  최종 plan weight/bias 두 개뿐이다. 실제 FP16 변경은 weight 18,015개, bias 73개다.
- **114개 실제 영상/시간 이력 입력으로 전체 원본·후보 ONNX를 GPU 실행**했다.
  허용한 75행 이외 출력의 최대 차이 0, 특징 추출용 출력 추가 전후 차이도 0이다.
- 분석용 FP64 행렬 계산과 실제 후보 FP16 ONNX의 최대 차이는 속도 0.0166 m/s,
  거리 0.2095 m, 가속도 0.00149 m/s²다. 표의 큰 실패 경향을 바꾸지 않는다.
- 별도 CPU 비교 그래프를 생성했지만 이번 새 그래프의 차량 실행/주행 검증은 하지 않았다.
  차량에는 기존 원본 제어와 기존 비교 후보가 그대로 남아 있다.

## 해석의 한계와 다음 방향

이번 실험은 더 많은 사건을 이용한 **출력층 재학습**이다. 전체 영상 신경망을
처음부터 학습하거나 신호등 객체/색상 분류기를 새로 학습한 작업은 아니다.
녹색 예측을 높이려는 학습이 적색에도 영향을 주는 결과로, 이번 자료와 최종 선형층
조합은 필요한 구분에 실패했다. 이것만으로 영상 특징에 신호 정보가 없다고 하거나,
전체 모델 개선이 불가능하다고 결론내릴 수 없다.

실시간 숨은 특징 자체는 로그에 저장되지 않았다. 기존 원본 영상으로 20 Hz 특징을
재구성해 학습했으며 warp, action_t=[0.475,0.375], 연산 장치 차이가 남는다.
구간별 원본 재생 v10과 기록된 원본 v10의 평균 절대 차이는 중앙값 0.316 m/s,
최대 구간 0.763 m/s다. 모델 간 비교는 동일한 재생 입력을 사용했지만 실차 출력의
비트 단위 재현이나 실차 출발시간 개선을 주장하지 않는다.

지금은 동일한 방식에 대기 프레임을 더 쌓기보다, 적색/녹색 전환을 구분하는
보조 학습으로 특징의 구별 능력을 먼저 평가하고 시간 특징층 또는 별도 신호 인식
경로를 포함한 학습으로 범위를 넓히는 것이 다음 과제다. 정답이 확실한 녹색 전환은
이번에도 두 사건뿐이며, 여러 교차로·조명 조건을 추가하는 작업은 여전히 도움이 된다.
신호출발 조건 변경으로 이 학습 실패를 우회하지 않는다.
