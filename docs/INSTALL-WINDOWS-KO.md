# Jetson 설치 안내 — 한글

최신 설치 안내는 Jetson 전용 저장소의 다음 문서에서 관리합니다.

**[Windows 초보자 설치 안내 열기](https://github.com/ajouatom/carrot-jetson/blob/main/docs/INSTALL-WINDOWS-KO.md)**

필요한 프로그램 설치, NAS 이미지 다운로드, 압축 해제·검사, Etcher 기록,
PC 핫픽스 복사·실행 명령, 첫 부팅과 Wi-Fi/IP/온도 확인, 오류 해결 및 선택적인 SSH 설정을 설명합니다.
큰 이미지는 NAS에 있으며 GitHub 소스 ZIP이나 모델 manifest는 설치 이미지가 아닙니다.

콤마에는 **Jetson 통합이 포함된 `carrot-wip`**을 사용합니다.
이전 `carrot-jetlink` 기능은 이 브랜치에 통합되었습니다.
[통합 내용과 검증 범위](jetson_wip_integration_20260927.md)를 확인하세요.
별도 `carrot-jetson` 저장소는 Jetson 쪽 실행 코드·설치·업데이트 도구를 관리하는 저장소로 유지합니다.

PC 오프라인 핫픽스로 준비한 카드의 실제 첫 부팅 시험은 아직 남아 있습니다.
이미 핫픽스를 설치하여 작동 중인 Jetson은 다시 이미지를 기록할 필요가 없습니다.
