# 영상 직접 판독 신호 정답지 — 2026-10-10

사용자는 차량 움직임을 정답으로 삼는 마지막 출력층 학습 대신, assistant가 영상을 보고
신호 정답지를 먼저 만들도록 요청했다. 불명확한 장면은 사용자에게 질문하도록 지정했다.
확보한 영상에서 신호 전환을 우선하여 **9개 사건, 237개 프레임**을 직접 판독했다.
이는 첫 묶음이며 전체 수집 영상의 판독 완료나 새로운 모델 학습을 뜻하지 않는다.

## 정답과 자료 구성

| 영상 판독 | 프레임 수 |
|---|---:|
| 적색 | 98 |
| 녹색 원형등과 좌회전 화살표 | 66 |
| 녹색이나 형태 불명확 | 17 |
| 좌회전 녹색이나 원형등 불명확 | 1 |
| 판단 불가 | 53 |
| 대상 차량 신호가 화면 밖 | 2 |

선명한 적색 92장과 원형녹색+좌회전 66장, 총 **158장**을 기본 지도학습/평가용으로
내보냈다. 이전 실험의 사건 단위 분리를 유지하여 학습 57장, 개발 57장, 별도 평가 44장이다.
중간 확신 24장과 판단 불가 53장, 화면 밖 2장은 별도 검토 목록에 남겼다.
서로 이웃한 프레임 수를 독립 사건 수로 해석해서는 안 된다.

전체 장면으로 차량용 신호의 적용 방향을 확인하고 각 선택 프레임의 확대 이미지를 판독했다.
회전 후 보이는 보행자 적색이나 옆 차로 차량의 이동은 내 차로 신호색의 정답으로 쓰지 않았다.
기존 CAN 차속·가속도·페달, planner 상태, ONNX 예측은 라벨 결정에 사용하지 않았다.
기존 로그에서는 영상 인덱스와 촬영 시각의 대응만 가져왔다.

라벨마다 영상/추출 이미지 SHA256, 세그먼트, 영상 프레임 번호, 카메라 frameId,
timestampEof, 신호색/형태, 확신, 출처, 검토용 ROI를 보존했다. ROI는 물체 검출 학습용
정밀 바운딩 박스가 아니다. 영상에서 실제 검토한 프레임에만 라벨을 부여하고 사이의
미검토 프레임으로 자동 보간하지 않는다.

7개 전환 사건의 마지막 적색과 첫 녹색 관측을 기록했다. 4개 사건은 선명하며 간격은
약 0.05~0.10초다. 3개 사건은 녹색이 어둡거나 형태가 불분명하고, 그중 한 사건은
관측 경계 사이가 약 4.05초이므로 정확한 신호 점등 시각으로 쓰지 않는다.
적색이 사라졌다는 이유만으로 이후 어두운 프레임을 녹색으로 확정하지 않았다.

공단 복귀길 두 교차로의 일반 신호/황색 점멸/소등 여부는 영상만으로 구별하기 어려워
사용자에게 장면 링크와 함께 질문했다. 해당 답변은 아직 대기 중이며 관련 프레임은
판단 불가로 보관한다. 추후 사용자 설명과 영상 판독의 출처를 별도로 유지한다.

## 저장 및 확인

개인 영상과 라벨은 `.analysis/archive/2026-10-10-signal-labels/`에만 저장했다.
`review.html`은 장면·신호·사용 구분 필터가 있는 로컬 검토 페이지다.
`labels.jsonl`, `supervised/*.jsonl`, `review_only.jsonl`, `transitions.json`과 재현 코드,
실제로 검토한 확대 이미지 및 설명을 함께 보관한다. 원본 영상은 복제하지 않고 기존
수집 archive의 경로와 해시를 참조한다.

237개 출처 프레임의 중복 없음, 원본/이미지 해시, 프레임별 결정의 유일성, 카메라 로그와
frameId/촬영 시각 일치, 전환 순서, 사건 분리, 학습용 목록의 불명확 라벨 제외를 검사했다.
검토 HTML의 로컬 링크와 카드 수도 확인했다. 이 검사는 영상 판독의 정확도를 독립적으로
보증하는 검수가 아니다.

이번 묶음은 같은 차/날짜/지역의 기존 검토 사건들이며 황색·점멸·야간 사례가 없다.
신호 인식 성능 개선은 아직 검증하지 않았다. 신호색은 출발 허가나 미래 x/v/a의 정답과
구별한다. 기존 내부 모델, 비교 모델 및 신호 출발 조건은 이번 작업에서 변경하지 않았다.
