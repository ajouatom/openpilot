## Repository policy

- `.gitattributes` disables content filters by default and retains binary byte
  preservation for ONNX files, the updater, and image/font/sound assets.
- Developer setup and device CI no longer run `git lfs pull`. The developer
  model check no longer suggests an LFS download.
- Process replay instructions no longer recommend committing logs through LFS.
- Existing NAS delivery for eGPU and Jetson models remains unchanged.
- Historical commits, tags, and other branches are not rewritten. Checking out
  an old LFS-bearing commit can still require LFS; this does not reset account
  usage or delete historical LFS storage.
- Compatibility tools remain: the installed git-lfs package, local cache pruning,
  old-device hook cleanup, release checks, and third-party/upstream dataset LFS
  clients. Their presence does not make current branch artifacts LFS downloads.
