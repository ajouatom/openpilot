# 신호 영역 학습·자동 탐색·차량 장치 시험 — 2026-10-10

사용자가 분석 후 중단하지 말고 실제 시험까지 진행하라고 요청했다. 확대된 신호 영역의
RGB CNN 학습, 색 특징 분류 가중치 학습, 위치를 알려주지 않는 전체 화면 탐색, 연결된
차량에서의 녹화 입력 ONNX 실행까지 완료했다. **신호 위치를 제공하면 개선되는 사례가
있지만, 자동 탐색은 후미등·다른 붉은 물체를 선택한다.** 기존 주행 ONNX의 x/v/a를
수정하거나 실차 제어 성능을 개선했다는 결과는 아니다.

## 자료와 학습

이전 [영상 정답](signal_visual_labels_20261010.md)의 사건 분리를 유지했다.
높은 확신도 신호 158장: 학습 57장/2사건, 개발 57장/2사건, 별도 평가 44장/3사건.
학습 사건에서 배경 16개, 개발 사건에서 배경 12개를 추가로 직접 확인했다.
배경에는 하늘·나무·건물·노면·차체가 있고 개발 배경에는 붉은 후미등도 있다.
신호 검토 영역은 사람이 지정한 넓은 영역이며 정밀 객체 박스는 아니다.

정답 SHA256은 `e8169cd7ce6b9893992bf7cf907aeb2ad6faecb763974972aeb4501e262d6ded`이다.
두 모델 모두 RGB 영상만 입력받고 CAN·주행 정책 특징·시간 이력은 사용하지 않는다.
고정 크기 RGB 96x32, float32 [0,1]로 리사이즈했다. 세 클래스는 배경/적색/녹색이다.
황색·점멸·신호 방향별 출발 허용은 학습 대상이 아니다.

1. **RGB CNN:** 3x3 Conv 3→12, ReLU, 2배 평균 풀링, 3x3 Conv 12→16,
   ReLU, 전체 평균/최댓값 연결, Linear 32→3. 2,179개 파라미터를 처음부터 학습했다.
   밝기·대비·채널 이득·작은 이동/노이즈 증강, 사건/클래스 균형 가중치,
   AdamW, weight decay 0.0001/0.001, 20/40/80/120 epoch에서 평가했다.
   개발 균형 로그 손실로 0.001/20 epoch를 선택했다. 후기 모델들은 학습 73/73이나
   개발 녹색을 모두 놓친다. 학습 교차로 과적합과 일반화 실패를 보여준다.
2. **색 특징 분류:** 첫 실패를 확인한 후 별도 탐색 실험으로 설계했다.
   고정 `RGB/(R+G+B+0.1)`와 `ReLU(3*normalized-1)`의 채널별 평균/최댓값,
   원본 RGB의 채널별 평균/최댓값을 합쳐 12개 특징을 만든다.
   Linear 12→3의 **39개 가중치/바이어스를 학습**했다. 영상망 전체 미세조정은 아니다.
   밝기/채널 이득 증강, 같은 그룹 가중치, AdamW, weight decay
   0.0001/0.01/0.1, 50/100/200/400 epoch 중 개발 로그 손실로 0.0001/400을 선택했다.
   주변 물체의 공간 형태를 이용하지 못하도록 한 단순 비교 모델이다.

각 실험의 선택을 저장한 다음 별도 평가 점수를 계산했다. 하지만 해당 사건은 이전
분석과 첫 실험에서 이미 봤으므로 **독립적인 새 검증이 아닌 재사용 회귀 사례**이다.
두 번째 방식까지 검토한 개발 점수에는 설계 선택 효과도 있다. 인접 프레임 수를
독립적인 교차로 사례 수로 해석해서는 안 된다.
