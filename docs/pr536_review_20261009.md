# PR #536 review and integration

Reviewed contributor commit `598d8e19877d1aec7040d7e5b7639fb74cfd7588`
against `carrot-wip` after the Cinque v3 rollback.

The PR removes YouTube broadcasting controls, services, manager processes and
dedicated encoder profiles. Ordinary recording, livestream/Carrot Vision and
external HUD encoding remain. Retired cereal union fields and historical replay
descriptions remain readable; their ordinal IDs must not be reassigned.
No stored user files or credentials are deleted by this integration.

Settings search adds shared Korean initial-consonant and multiword matching.
On narrow screens, results appear under the search field without moving the
focused input. Wide screens keep their separate results pane. Detail navigation,
favorites and control styling are carried across both locations.

Review found that the new inline location was omitted by the existing live-value
refresh eligibility check. Returning to cached results also did not restart the
refresh, and restore-driven rendering was cancelled because the separate items
screen was hidden. The integration fixes all three cases and adds regressions.

The old generic navigation test still expected browser history.back rather than
the already-established settings parent action; its assertion now matches that
action, which retains behavioral tests. Wiki catalog counts account for the
three removed YouTube settings and assert their absence.

Validation: all 818 Web tests, 86 focused server tests and 25 Wiki tests pass.
Web assets are rebuilt from source. The PR's documentation failure came from
the broad process_config.py-to-driver-monitoring mapping; only YouTube processes
are removed, so the merge records a scoped documentation exception. Removed
setting references are already removed from both user guides. Wiki publication
uses the existing settings synchronization workflow.

Cinque v3 selection, internal/DM models, Jetson and recent startup/HUD fixes are
preserved. Desktop tests do not validate phone IME/keyboard behavior or physical
camera/encoder operation. Private reproduction logs are retained locally under
`.analysis/archive/2026-10-09-pr536/`.
