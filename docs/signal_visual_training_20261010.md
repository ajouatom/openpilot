# 영상 신호 정답 기반 재학습 — 2026-10-10

사용자는 정답지 작성 후 재학습을 멈춘 이유를 물었다. 이어서 정답지에 기반한
**신호 분류층 학습, 사건별 검증, 새 ONNX 생성**을 완료했다. 새 분류기는 적색/녹색
점수를 출력하며 기존 주행 모델의 x/v/a를 대체하거나 수정한 모델은 아니다.
개발 검증 기준을 통과하지 못했으므로 차량에 설치하지 않았다.

## 학습 범위

237개 직접 판독 프레임 중 높은 확신의 158장만 기본 정답으로 사용했다.
이전 사건 단위 분리를 유지하여 학습 57장(2사건), 개발 57장(2사건), 별도 평가
44장(3사건)으로 구분했다. 중간 확신 24장은 참고 평가만 하고 불명확 53장과
신호 화면 밖 2장은 정확도 계산에 넣지 않았다. 기본 정답은 적색과 원형녹색+좌회전이다.

기존 내부 ONNX의 `current_hidden_flat` 512차원 특징은 그래프 선행 입력을 추적하면
`img`, `big_img`에만 연결된다. 각 카메라의 현재/4프레임 전 영상으로 만들어지며,
CAN 속도·가속도·페달, desire, 통행 방향, action_t, 긴 정책 이력은 이 그래프에
들어가지 않는다. 카메라 보정은 영상 전처리에 사용한다.

이 영상 특징에 새로운 L2 로지스틱 신호 분류층을 학습했다. 비교용으로 기존
`policy/relu_7` 256차원 특징에도 같은 정답/방식의 분류층을 학습했다. 후자는
시간 이력과 의도/문맥을 포함하므로 영상만의 실험이라고 부르지 않는다.
정규화 통계는 학습 자료만 사용했고 사건/색상 그룹마다 총 가중치를 같게 했다.
정규화 강도 6종 중 개발 자료의 사건 균형 로그 손실로 선택한 뒤 별도 평가를 했다.
두 경우 모두 0.001이 선택되었다. 영상 추출기 자체는 고정했고 전체 신경망 미세조정은 하지 않았다.

## 결과와 해석

영상 분류기는 개발 자료에서 적색 34장을 모두 맞혔지만 녹색 23장 중 11장을 놓쳤다.
실패는 좌회전 교차로에 집중된다. 별도 평가 44장은 적색 36장과 녹색 8장으로,
**학교 앞의 어두운 녹색은 이 높은 확신 자료에 포함되지 않는다.** 그 장면의 중간 확신
녹색 11장을 따로 보면 10장을 적색으로 분류한다. 44/44만으로 학교 앞 문제가
해결되었다거나 일반적인 100% 정확도라고 주장할 수 없다.

정책 특징 분류기는 별도 평가 적색 9장을 녹색으로 분류하며 그중 8장이 학교 앞이다.
이는 서로 다른 특징 단계의 비교이고 CPU/GPU 재현 차이도 있으므로 차량 상태를
빼서 개선되었다는 인과 결론을 낼 수 없다. 작은 영상 특징에 신호 정답을 연결하는
실험은 가능하지만, 이번 분류층과 자료만으로 안정적인 구별은 달성하지 못했다.

재현 입력을 확인하면 학교 앞 39.40초의 신호 검토 영역은 좁은 전방 모델 입력에서
y=-43.31..-3.06으로 투영되어 위쪽 범위 밖에 있다. 광각 입력에는 신호가 작게 남는다.
확인한 다섯 대표 영역 중 네 개가 좁은 전방 입력 밖이다. 사람이 원본을 확대해 보는
조건과 모델 입력의 차이를 보여주지만, 실제 기기의 warp와 픽셀 단위 동등성을 검증한
것은 아니며 이 현상만으로 오감지 원인을 확정하지 않는다. 향후 영상 특징 미세조정이나
신호 영역을 더 잘 보존하는 별도 영상 경로를 검토할 근거이며 이번에 적용한 변경은 아니다.
