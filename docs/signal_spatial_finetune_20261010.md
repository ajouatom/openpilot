# 신호 위치·정지선 정답을 추가한 원본 ONNX 학습 — 2026-10-10

사용자가 요청한 신호 위치 정답 보강과 원본 주행 ONNX 재학습을 실행했다.
네 후보 모두 개발 검증에 실패했다. 선택 후보도 최종 평가에 실패했으며 차량에
설치하지 않았다. 원본 ONNX의 재학습이 불가능하다는 뜻은 아니지만, 이번 위치·거리
정답 추가가 사용자가 원하는 오출발 해결로 이어졌다는 증거는 얻지 못했다.

## 실제로 학습한 부분

원본 내부 ONNX SHA256은
`f73a9e535523d5e9acb9e642c64e33d631825dc8ba74123757d107cedd047bb5`이다.
이전 [영상층 학습](signal_vision_finetune_20261010.md)보다 앞쪽인
`vision/add_8`(256×8×16)부터 계산을 재구성했다. stage2 block5, stage3,
마지막 convolution/SE/projection의 기존 가중치 6,152,000개를 미세조정했다.
더 앞쪽 영상층, 시간 처리층, 최종 주행 출력층 가중치는 고정했다.
변경된 영상 특징이 기존 주행 출력층에 들어가므로 x·v·a도 달라진다.
각 후보의 과거 영상 특징을 다시 계산하며, 원본 모델의 과거 특징을 재사용하지 않는다.

학습할 때만 전방/광각별 신호 위치의 방해물·적색·녹색 분류와 좌표,
정지선 좌표·거리 보조 head를 붙였다. 내보낸 ONNX에서는 이 head를 제거했다.
ONNX의 노드·입출력 구조와 실행 프로세스 수는 원본과 같다.
별도 판독기를 차량 제어에 연결하거나 신호 출발 조건을 변경한 작업이 아니다.

## 영상 검토와 정답의 범위

기존 37개 구간의 전방/광각 44,400쌍을 사용했다. 야간 1091의 11–14는 학습,
15–17은 개발 검증, 18–22는 최종 평가로 분리했다. 주간 108d 및 108e 일부를
학습하고 나머지 108e를 개발 검증, 주간 108c와 해질녘 1090을 평가에 사용했다.
같은 신호 대기는 하나의 역할에 묶었다. 이미 검토한 동일 차량·날짜·지역의 자료이고
장소 중복도 있으므로 새로운 장소의 맹검 평가는 아니다.

전체 장면과 확대 영상을 검토해 신호 위치, 색, 주변 간판·차량등·보행 신호를
표시했다. 222개 위치 제안 중 206개를 승인했고, 실제 모델 입력 화면 안에 있는
102개만 사용했다. 학습 41개(방해물 21/적색 9/녹색 11), 개발 25개(6/13/6),
평가 36개(0/22/14)이다. 프레임 수이며 독립적인 교차로 수가 아니다.
미표시 영역은 무시했다. 신호 전체를 빠짐없이 표시한 탐지 데이터셋이나
차선별 화살표 통행 허가 정답은 아니다. 색은 사람이 장면을 보고 정했고,
색상 픽셀 계산은 정해진 영역 안에서 점의 좌표를 보정하는 데만 썼다.

정지선은 12개 위치를 영상에서 확인했다. 가까워져 모델 입력 밖으로 나간 4개는
학습에서 제외했다. 남은 8개는 학습 6개와 평가 2개이다. 학습 6개는 한 번의
접근에서 약 38.7–6.1m에 해당한다. 기록된 카메라 높이·보정값과 평면 도로 가정으로
계산한 약한 거리 정답이며 측량값이 아니다. 평가 2개의 거리 변화는 기록 속도를
적분한 이동 거리와 약 6.9m 어긋나므로 좌표만 남기고 거리 정답은 제외했다.
픽셀·피치·높이 변화에 따른 불확실성 범위를 기록했지만 학습 손실에는 점 추정값을
사용했다. 범퍼 기준 정지 여유나 최적 감속 궤적을 새로 만든 것은 아니다.

x·v·a 정답은 이전과 같은 적색 정지 861개, 녹색 기록 궤적 95개,
기존 출력 보존 576개이다. 적색 정지는 실제 속도 절댓값 0.03m/s 미만이고
이후 10초도 적색인 경우로 한정했다. 0.5초 이후 x·v·a를 0으로 학습한다.
녹색은 기록된 운전 궤적이며 장애물 없는 출발 허가나 최적 궤적의 정답이 아니다.
움직이는 적색 접근의 감속 정답을 새로 추가하지는 않았다.

## 비교 방법

원본에서 각각 시작하는 네 후보를 고정했다. `deeper_control`은 추가 위치·거리
정답의 영상층 gradient를 끊은 대조군이다. `spatial_weak`와 `spatial_strong`은
위치 손실 비중 0.1과 0.5, `spatial_stop`은 위치 0.1 및 정지선 손실 0.2를 쓴다.
대조군도 진단용 보조 head를 학습하지만 영상층에는 영향을 주지 않는다.
보조 head 손실 비중도 다르므로 보조 분류 정확도만으로 영상층의 효과를 단정하지 않는다.

Adam, seed 20261010, 각 3,000단계, 주행 배치 8, 보조 배치 24,
영상층 학습률 0.000002, 보조 head 학습률 0.001이다. 먼저 원본 특징을 고정하고
보조 head만 600단계 준비했다. 궤적·다른 주행 출력·영상 출력·특징 보존 손실과
기존 전역 색상 손실을 함께 쓴다. 첫 단계에서 실제 깊은 영상층까지 각 손실의
유한하고 0이 아닌 gradient가 전달되는지 검사했다.

모든 후보를 FP16 가중치로 반올림한 뒤 44,400프레임을 다시 계산했다.
개발 검증 위반 개수가 적은 후보, 동률이면 적색 사건별 평균 v10 오차가 작은
후보를 선택하고 선택 기록을 저장한 다음 최종 평가를 열었다.
이전 실험의 기존 출력 보존·적색·녹색 기준을 유지하며, 하나라도 실패하면
차량 적용 후보로 승인하지 않는다. 시간별 예상 y의 변화는 실제 차량 횡이동이나
물리적 조향 악화를 측정한 결과가 아니다.

## 내보낸 ONNX 검증

원본 계산을 학습용으로 재구성한 결과를 44,400프레임에서 비교했다.
x 최대 차이 0.3934m, v 최대 차이 0.0516m/s로 사전에 정한 계산 허용 범위
x<1m, v<0.15m/s 안에 들어왔다. 이는 계산 재구성 검사이며 주행 품질 기준과 별개다.

네 ONNX를 각각 실제 입력 259개에서 검사했다. 모두 checker를 통과하고 원본과
노드·입출력이 같으며, 바뀐 initializer 39개가 전부 영상층이라는 것을 확인했다.
시간 처리층과 최종 출력층 가중치는 그대로다. 각 후보에서 다시 계산한 과거 특징을
넣었을 때 학습용 계산과 완성 ONNX의 최대 차이는 모든 후보를 통틀어
x 0.256m, v 0.048m/s 미만이었다. 출력은 모두 유한하며 네 후보 모두 계산 검사를
통과했다. 이 검사 통과가 성능 실패를 상쇄하지는 않는다.

영상 재생은 기록된 카메라 보정값, 기존 실험의 최근접 YUV 변환,
고정 `action_t=(0.475,0.375)` 및 동일 desire 재구성을 사용한다.
각 모델이 자기 과거 특징을 유지한다. 차량의 실제 카메라 처리·QCOM 실행과
완전히 같은 계산이라는 뜻은 아니다. 장치용 컴파일, 전체 제어기/MPC,
실제 차량 응답이나 정지선 여유 검증을 수행한 결과도 아니다.

선택 후보와 대조군을 각각 야간 12개·주간 학교 4개 구간의 원본 영상
19,200프레임에서 끝까지 재생했다. 선택 후보의 학습용 계산 대비 최대 차이는
x 0.413m/v 0.060m/s 미만, 대조군은 x 0.307m/v 0.070m/s 미만이었다.
두 모델 모두 자기 ONNX 출력으로 과거 특징을 유지했고 계산 검사를 통과했다.

## 실제 문제 구간의 출발 판정 재생

기존 `check_model_stopping` 함수를 그대로 실행하고 기록된 이전 xState,
차량 상태와 레이더를 제공했다. 기록 모델 출력을 넣은 판정은 사건 창의
318/318개 상태와 일치했다. 영상 경계 7개 행은 건너뛰었다.
아래는 각각 7초·6초·3초 사건 창 안의 잘못된 녹색/출발 판정 프레임 수이다.
실제 차량 출발 횟수나 닫힌 제어 루프의 결과가 아니다.

| 적색 사건 | 원본 ONNX | 대조군 | 위치 강하게 학습 |
|---|---:|---:|---:|
| 야간 12번 | 88 | 89 | 89 |
| 야간 16번 | 19 | 19 | 19 |
| 야간 20번의 짧은 오판정 | 1 | 0 | 0 |

주요 두 오출발은 해결되지 않았다. 첫 사건의 v10 최대값은 원본 14.023m/s에서
선택 후보 14.406m/s로, 두 번째는 9.859→10.195m/s로 오히려 커졌다.
세 번째의 한 프레임 감소만으로 문제 해결을 선언할 수 없다.

녹색 전환 후 첫 출발 판정 시점은 야간 14번에서 1.575→0.868초로 빨라졌다.
12번과 17번은 그대로였고, 20번은 0.312→0.254초, 21번은 0.957→0.914초였다.
**이 다섯 결과는 대조군과 위치 학습 후보가 모두 같았다.** 따라서 신호 위치
정답 추가의 고유한 효과라고 할 수 없다. 14번은 학습한 사건이며 실제 차량의
출발 지연이나 다른 교차로 일반화를 검증한 결과가 아니다.

이번 결과로 원본 ONNX 수정·내보내기·검증 절차는 확인했지만 안정적인 신호
개선 방법을 확보하지는 못했다. 작은 위치 정답과 한 번의 정지선 접근을 더한
현재 손실 구성은 목적을 달성하지 못했다. 다른 장면의 분류·거리 정답 확대와
적색 접근/정지/녹색 전환의 원하는 궤적 정답은 별도의 후속 과제다.
추가 영상의 양이나 반복 학습 횟수만으로 해결된다고 약속할 수 없다.
차량, 설치 모델, 출발 조건, 별도 observer에는 변경을 가하지 않았다.
