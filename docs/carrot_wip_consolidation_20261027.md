# carrot-wip 통합 변경 안내

carrot-nav와 carrot-nav-blink의 누적 변경을 carrot-wip로 통합합니다. 기존 carrot-wip의 Bosch 레이더 지원도 유지합니다.

- 모델 선택: Carrot Web에서 N16 Nav 또는 Flip Flop을 선택하고 재부팅하면 eGPU·Jetson에 함께 적용됩니다. 내부 모델은 CD210으로 고정합니다.
- NOO 표시: 내비 경로를 사용하는 N16 Nav에 지원 여부를 표시합니다. Flip Flop은 내비 입력을 사용하지 않습니다. MD v3는 선택 목록에서 제거했습니다.
- 모델 관리: 배포자가 정한 목록만 제공하며 사용자 숨기기·삭제 메뉴는 없습니다. 폐기 모델의 사용하지 않는 캐시는 오프로드에서 정리합니다.
- 내비 연동: 외부 내비의 경로·지도 입력과 모델용 경로 영상, USB 화면의 지도 표시를 통합했습니다. 유효한 위치와 경로가 필요합니다.
- Jetson 통신: 공유 메모리 입력 전달, 전송량 축소, 입력 변환과 GPU 상태 처리, 다음 프레임용 지도 전송 등 검증한 최적화를 통합했습니다. 모든 상황에서 50ms 이하를 보장하는 것은 아닙니다.
- Jetson 복구: 초기 연결 대기 표시, USB 재연결·DHCP 종료 처리, TensorRT 캐시와 초기화 실패 복구를 개선했습니다.
- USB 디스플레이: HUD·지도·신호등 관측 결과를 표시합니다. ESP32-S3 디스플레이 지원은 제거했습니다.
- 깜박이: 지원하는 Ioniq 5 PE·Jetson USB2CAN 구성에서 블루투스 및 ATC 깜박이 유지·취소를 지원합니다. 교차로 정차 중 조기 해제를 줄이고, 확인된 ATC 점등이 꺼진 경우 한 번만 복구를 시도합니다.
- ATC 4번: 차선변경 가능 속도이고 우회전까지 250m 이내일 때 턴 시작 전까지 우측 차선·BSD·후방 거리 조건을 확인해 우측 깜박이만 켭니다. 기존 차선변경 코드가 이어받으며 수동·리모컨 동작은 바꾸지 않습니다. 기본 설정은 바꾸지 않습니다.
- 정차 중 운전자 감시: SoftHold·확인된 신호 정지·앞차 정지 조건에서 판정을 잠시 멈추고 출발하거나 입력이 무효해지면 재개합니다.
- Tesla: 검토한 자동 방향지시등 연동을 포함합니다. 현대 SPAS 시험은 기본 꺼짐이며 기존 차량 설정을 변경하지 않습니다.

기존 선택값이 없는 carrot-wip 사용자는 외부 모델이 N16 Nav로 초기화됩니다. 저장된 모델 선택은 유지하며 내부 CD210은 바뀌지 않습니다. 일반 설치는 Git Pull 후 재부팅입니다. Jetson 런타임이 바뀌는 장치는 Jetson도 재부팅해야 합니다.

새 ATC 기능의 로컬 검증은 실제 도로 주행 검증을 뜻하지 않습니다. 차량 적용 결과와 통합 CI 결과는 완료 후 기록합니다.
