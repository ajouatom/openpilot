## Startup and Jetson scope

This branch includes the shared October 7 selected-model startup correction and
USB cluster core4 placement. With an eGPU detected at boot, selected-model
delivery precedes build validation and manager startup. A different cached
external model cannot be selected as fallback. See `egpu_startup_selection_20261007.md`
and `camera_core5_trial.md` for policy and limits.

The public [ONNX export catalog](https://huggingface.co/commaai/openpilot_driving_models/tree/main)
still lists only 1a421175 and f78ed37d at inspection; 870a4823 is absent. The AMD PKL
is not a TensorRT ONNX input. Jetson therefore retains Cinque v2 and the existing
host release; no Jetson image, release or model contract is changed. A matching
export and separate numerical/runtime validation are required for Jetson MDM.
