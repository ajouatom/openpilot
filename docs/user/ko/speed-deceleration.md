# 속도·감속 상세 설정

[English](../en/speed-deceleration.md)

> [!NOTE]
> 이 문서는 `carrot-wip` 코드와 함께 관리하는 사용자 설명서 원본입니다. 사용자 동작이 바뀌면 관련 코드·테스트와 같은 변경에서 이 문서도 갱신합니다.

이 페이지는 `carrot-wip`의 실제 코드를 기준으로 **속도·감속 22개 설정**을 설명합니다. 카메라 목표속도, 감속 시작 거리, 차량 순정 내비 CAN, 도로 제한속도 연동, 방지턱, 커브·경로·모델 속도와 신호 정지 보정이 서로 어떻게 연결되는지 사용자 관점에서 정리했습니다.

모든 값은 Carrot Web의 **설정 → 주행 제어 → 속도·감속**에서 변경합니다.

> [!CAUTION]
> 이 설정은 차량의 목표 속도와 감속 계획에 영향을 줄 수 있습니다. 내비게이션·제한속도·거리·모델 정보는 틀리거나 늦을 수 있으며, 기능이 켜져 있어도 모든 카메라·방지턱·커브·신호를 인식하지 않습니다. 운전자가 항상 도로와 차량을 직접 확인하고 즉시 개입해야 합니다.

## 최종 목표속도는 여러 후보 중 가장 낮은 값입니다

현재 코드는 다음 후보를 모아 가장 낮은 값을 `desired_speed`로 선택합니다.

| 후보 | 대표 설정·입력 |
|---|---|
| 카메라·구간단속·방지턱 | 내비 안전운전 정보, `AutoNaviSpeed*` |
| 도로 제한속도 + 오프셋 | `AutoRoadSpeedLimitOffset` |
| 비전 커브 | `AutoCurveSpeedFactor`, `TurnSpeedControlMode` |
| 경로 턴 | `MapTurnSpeedFactor`, `TurnSpeedControlMode` |
| 모델 미래속도 | `ModelTurnSpeedFactor` |
| 별도 자동 턴 제어 | `AutoTurnControl` 계열 |

따라서 한 설정을 올렸는데 속도가 변하지 않으면 다른 후보가 이미 더 낮은지 확인해야 합니다. 화면에 표시되는 감속 소스, 이벤트 종류, 목표 제한속도와 남은 거리를 함께 보세요.

> [!NOTE]
> 당근맨(CarrotMan)과 CarrotLink는 현재 지원하지 않습니다. 외부 경로·TBT·도로 정보가 필요한 기능은 입력 환경에 따라 동작하지 않을 수 있으며, 이 페이지의 코드 설명이 해당 앱이나 연결 방식의 지원을 뜻하지 않습니다.

### 초기값이 서로 다르게 보일 수 있습니다

Carrot Web 기본값 복원에 쓰이는 `carrot_settings.json`과 Params 최초 생성에 쓰이는 `params_keys.h`의 값이 일부 다릅니다.

| 파라미터 | 설정 카탈로그 기본값 | Params 최초값 |
|---|---:|---:|
| `AutoCurveSpeedFactor` | 100 | 120 |
| `AutoNaviSpeedCtrlEnd` | 6 | 7 |
| `AutoNaviSpeedDecelRate` | 200 | 120 |
| `MapTurnSpeedFactor` | 100 | 90 |
| `AutoRoadSpeedAdjust` | 0 | 50 |

복원 버튼의 숫자보다 **내 장치에 현재 표시된 값**을 먼저 기록하고, 한 번에 한 항목만 바꾸세요.

<a id="speed-camera"></a>
## 1. 과속카메라

관련 설정은 `AutoNaviSpeedCtrlMode`, `AutoNaviSpeedCtrlEnd`, `AutoNaviSpeedDecelRate`, `AutoNaviSpeedSafetyFactor`, `AutoNaviCountDownMode`, `VehicleNaviCanControl`, `VehicleNaviSchoolZoneControl`, `VehicleSpeedCameraControlMode`, `VehicleSpeedCameraDistanceTime`입니다.

### `AutoNaviSpeedCtrlMode`

| 값 | 감속 대상 |
|---:|---|
| 0 | 내비 안전운전 감속 안 함 |
| 1 | 과속카메라·구간단속 |
| 2 | 과속카메라·구간단속 + 과속방지턱 |
| 3 | 과속카메라·구간단속 + 과속방지턱 + 이동식카메라 |

이 설정은 내비게이션에서 이벤트 종류, 제한속도와 거리를 정상적으로 받아야 동작합니다. 구간단속 중에는 단속 종료 거리까지 목표속도를 계속 유지하고, 이동식카메라 이벤트는 `3`에서만 사용합니다.

### 차량 순정 내비 CAN 제어

`VehicleNaviCanControl`은 지원되는 Hyundai/Kia CAN-FD 차량에서 순정 내비가 제공하는 카메라·방지턱의 실제 거리를 감속에 사용합니다. Kia PV5에서는 일반 카메라와 방지턱만 지원하며, 구간단속과 `VehicleNaviSchoolZoneControl`은 필요한 주기 상태 신호가 아직 검증되지 않아 적용하지 않습니다.

이 기능은 기본값이 꺼진 실험 기능입니다. 화면의 이벤트 종류, 제한속도와 남은 거리가 실제 도로와 일치하는지 먼저 확인하고, 일치하지 않으면 즉시 끄세요.

### `VehicleSpeedCameraControlMode`

이 설정은 차량 CAN으로 받은 카메라·구간단속·30km/h 구간 감속에만 적용하며 Carrot Navi의 카메라 정보에는 영향을 주지 않습니다.

| 값 | 가속페달 동작 |
|---:|---|
| 0 | 차량 수신 카메라 감속을 사용하지 않음 |
| 1 | 가속페달 상태와 관계없이 항상 감속 적용 |
| 2 | 카메라 목표가 현재 차량속도보다 낮아 실제 감속이 시작된 뒤 새로 가속페달을 밟으면, 현재 이벤트를 무시하고 감속구간에서 가속으로 도달한 최고속도를 하한으로 유지 |
| 3 | 가속페달을 밟는 동안 차량 수신 카메라 감속을 중단하고, 놓으면 다시 적용 |

`2`에서는 감속이 시작되기 전에 밟아 계속 유지한 가속페달이 하한을 미리 만들지 않습니다. 실제 감속 중 새로 가속페달을 밟으면 현재 이벤트를 무시하려는 의사로 판단하고, 가속 중 도달한 최고속도까지 하한을 높입니다. 페달을 놓아도 같은 이벤트 동안에는 그 속도 아래로 추가 감속하지 않으며, 브레이크 입력, 정차, 제한속도·감속 소스 변경 또는 이벤트 종료 시 초기화됩니다.

### `VehicleSpeedCameraDistanceTime`

차량이 실제 카메라 거리를 제공하지 않고 단속속도만 보낼 때 가상 감속거리를 만듭니다. 화면의 `6.0초`는 50km/h 카메라에서 약 300m, `6.2초`는 약 310m의 가상거리를 뜻하며 변경값은 주행 중 약 1초 안에 반영됩니다.

### `AutoNaviSpeedSafetyFactor`

카메라 목표속도는 다음처럼 계산합니다.

    카메라 목표속도 = 수신한 제한속도 × 안전비율 ÷ 100

| 제한속도 | 비율 | 목표속도 |
|---:|---:|---:|
| 60km/h | 100% | 60km/h |
| 60km/h | 105% | 63km/h |
| 100km/h | 95% | 95km/h |

이 값은 계기판 오차나 법적 허용 범위를 보장하는 설정이 아닙니다. 제한속도 정보 자체가 잘못되면 계산 결과도 잘못됩니다.

### `AutoNaviSpeedCtrlEnd`

이 값은 카메라를 지난 뒤 몇 초 동안 감속한다는 뜻이 아닙니다. 코드에서는 목표속도로 달릴 때의 거리 여유를 계산합니다.

    감속 완료 여유거리 = 목표속도(m/s) × 완료 시간(s)

예를 들어 목표 60km/h는 약 16.7m/s입니다.

- 6초: 카메라 약 100m 전까지 목표속도에 도달하도록 계산
- 10초: 카메라 약 167m 전까지 목표속도에 도달하도록 계산

값을 높이면 더 먼 지점에서 감속을 마치려 하므로 전반적으로 감속이 일찍 끝납니다. 너무 높으면 오랫동안 낮은 속도를 유지할 수 있습니다.

### `AutoNaviSpeedDecelRate`

저장값에 `0.01m/s²`를 곱해 감속 가능 속도 곡선을 계산합니다.

| 저장값 | 계산에 쓰는 감속률 | 체감 방향 |
|---:|---:|---|
| 80 | 0.80m/s² | 더 멀리서 완만하게 시작 |
| 120 | 1.20m/s² | 중간 |
| 200 | 2.00m/s² | 더 가까이서 강하게 시작 가능 |

핵심은 **값이 낮을수록 더 일찍 감속**한다는 점입니다. 코드는 남은 거리에서 목표속도까지 감속할 수 있는 현재 속도 상한을 다음 관계로 계산합니다.

    허용속도² = 목표속도² + 2 × 감속률 × (남은거리 - 완료 여유거리)

감속이 너무 늦으면 먼저 값을 한 단계 낮추고, 너무 일찍 시작하면 한 단계 높입니다. `AutoNaviSpeedCtrlEnd`와 동시에 바꾸면 원인을 구분하기 어렵습니다.

### `AutoNaviCountDownMode`

| 값 | 화면 카운트다운 |
|---:|---|
| 0 | 표시 안 함 |
| 1 | 턴 지점 + 속도 이벤트, 방지턱 제외 |
| 2 | 턴 지점 + 속도 이벤트 + 방지턱 |

카운트다운은 남은 거리와 현재 속도로 예상 초를 표시하는 기능입니다. 감속 계산 자체의 시작 시점이나 강도를 바꾸지 않습니다.

### 카메라 감속 조정 순서

1. 화면에서 이벤트 종류, 제한속도와 남은 거리가 맞는지 확인합니다.
2. `AutoNaviSpeedSafetyFactor`로 목표속도만 먼저 정합니다.
3. `AutoNaviSpeedCtrlEnd`로 목표속도 도달 위치를 정합니다.
4. `AutoNaviSpeedDecelRate`로 접근 감속 곡선을 한 단계씩 조정합니다.
5. 같은 카메라와 비슷한 진입 속도에서 반복 비교합니다.

## 2. 도로 제한속도

관련 설정은 `AutoRoadSpeedLimitOffset`, `AutoRoadSpeedAdjust`, `AutoSpeedUptoRoadSpeedLimit`입니다. 카메라 이벤트 감속과 달리 도로의 현재 제한속도를 크루즈 설정속도 또는 최종 속도 후보에 반영합니다.

### `AutoRoadSpeedLimitOffset`

유효한 도로 제한속도가 30km/h 이상이고 내비 정보가 활성 상태일 때 다음 후보를 만듭니다.

    도로 목표속도 = 도로 제한속도 + 오프셋

| 값 | 최종 속도 후보에서의 의미 |
|---:|---|
| -1 | 도로 제한속도 + 오프셋 후보를 사용하지 않음 |
| 0 | 제한속도 그대로 |
| 5 | 제한속도보다 5km/h 높게 |

다만 `-1`을 모든 기능의 완전한 OFF로 보면 안 됩니다. `CruiseSpeed1=0` 또는 `AutoRoadSpeedAdjust=-1`의 별도 계산에서는 오프셋이 음수일 때 `AutoNaviSpeedSafetyFactor`를 곱하는 분기로 사용합니다.

### `AutoSpeedUptoRoadSpeedLimit`

선행차를 따라가는 상황에서 크루즈 설정속도를 다음 상한까지 자동으로 올립니다.

    자동 증가 상한 = 도로 제한속도 × 설정비율 ÷ 100

자동 증가는 다음 조건을 모두 만족할 때 5km/h 단계로 진행됩니다.

- 자동 속도 증가가 일시정지되지 않음
- 선행차가 약 60m 안에 있음
- 선행차 속도 + 5km/h가 현재 설정속도보다 큼
- 현재 설정속도가 계산된 상한보다 낮음

`0`이면 기능을 끕니다. 감속 버튼이나 브레이크로 자동 증가가 일시정지될 수 있고, 가속 버튼·가속 페달 입력이나 정차 상태에서 다시 풀릴 수 있습니다.

### `AutoRoadSpeedAdjust`

> [!IMPORTANT]
> 현재 코드에서 이 설정은 `AutoSpeedUptoRoadSpeedLimit`로 계산한 상한이 1km/h 미만이면 실행되기 전에 반환됩니다. 즉 `AutoSpeedUptoRoadSpeedLimit=0`이면 `AutoRoadSpeedAdjust`도 사실상 적용되지 않습니다.

| 값 | 제한속도가 바뀔 때의 현재 코드 동작 |
|---:|---|
| -1 | 제한속도가 오르거나 내려갈 때마다 새 도로 목표로 즉시 맞춤 |
| 0 | 기존 설정속도 유지 |
| 1~99 | 제한속도가 내려갈 때만 현재 설정속도와 새 제한속도의 가중 중간값으로 낮춤 |
| 100 | 제한속도가 내려갈 때 새 제한속도로 낮춤 |

50%이고 현재 설정속도 100km/h, 새 제한속도 60km/h라면 `(100 × 0.5) + (60 × 0.5) = 80km/h`로 낮춥니다. 이 1~100 분기에서는 오프셋이나 안전비율이 아니라 수신한 도로 제한속도 자체를 사용합니다.

`-1`에서는 다음처럼 새 목표를 정합니다.

- `AutoRoadSpeedLimitOffset >= 0`: 제한속도 + 오프셋
- `AutoRoadSpeedLimitOffset < 0`: 제한속도 × 카메라 안전비율

### 세 설정을 함께 보는 예

| 원하는 동작 | 시작점 예시 |
|---|---|
| 도로 제한속도 후보만 적용 | 오프셋 0 이상, 자동 증가 0 |
| 선행차를 따라 제한속도까지 자동 증가 | 자동 증가 100%, 도로 조정 0 |
| 제한속도가 낮아질 때 절반만 반영 | 자동 증가 100%, 도로 조정 50 |
| 제한속도가 바뀔 때마다 즉시 동기화 | 자동 증가 100% 이상, 도로 조정 -1 |

마지막 구성은 잘못된 제한속도 정보에도 즉시 반응하므로 특히 주의하세요.

## 3. 과속방지턱

관련 설정은 `AutoNaviSpeedBumpTime`, `AutoNaviSpeedBumpSpeed`입니다. 방지턱 감속은 `AutoNaviSpeedCtrlMode >= 2`이고, 내비가 방지턱 종류와 거리를 제공하며, 코드가 고속도로가 아닌 도로 범주로 판단할 때 사용합니다.

### `AutoNaviSpeedBumpSpeed`

방지턱의 목표 통과 속도입니다. 저장값을 km/h로 그대로 사용합니다.

- 높이면 더 빠르게 통과
- 낮추면 더 느리게 통과

차량 높이·서스펜션·방지턱 형상에 따라 체감이 크게 다릅니다. 인식되지 않은 방지턱에는 아무 효과가 없습니다.

### `AutoNaviSpeedBumpTime`

카메라의 완료 시간과 같은 방식으로 목표속도에 도달할 여유 거리를 만듭니다.

    방지턱 완료 여유거리 = 방지턱 목표속도(m/s) × 설정 시간(s)

목표 36km/h는 10m/s이므로:

- 1초: 방지턱 약 10m 전까지 목표속도 도달
- 3초: 방지턱 약 30m 전까지 목표속도 도달

값을 높이면 더 일찍 목표속도에 도달합니다. 접근 감속 곡선의 강도는 별도 항목이 아니라 `AutoNaviSpeedDecelRate`를 함께 사용합니다.

카메라와 마찬가지로 방지턱 신호가 실제 감속을 시작한 뒤 새로 가속페달을 밟으면 현재 방지턱을 무시하려는 의사로 판단합니다. 감속구간에서 가속으로 도달한 최고속도를 하한으로 유지하고, 방지턱 이벤트가 끝나면 초기화합니다. 감속 전부터 계속 밟고 있던 가속페달은 오버라이드를 시작하지 않습니다.

### 방지턱이 이상할 때

| 증상 | 확인 순서 |
|---|---|
| 전혀 감속하지 않음 | 모드 2 이상 → 이벤트 종류 22 → 남은 거리 → 도로 범주 |
| 너무 늦게 감속 | `AutoNaviSpeedDecelRate`를 낮추거나 `BumpTime`을 높임 |
| 너무 일찍 속도가 낮아짐 | `BumpTime`을 낮추거나 감속률을 높임 |
| 통과 속도 자체가 부적절 | `AutoNaviSpeedBumpSpeed`만 한 단계 조정 |

<a id="curve-turn"></a>
## 4. 커브·턴

관련 설정은 `AutoCurveSpeedFactor`, `AutoCurveSpeedLowerLimit`, `TurnSpeedControlMode`, `MapTurnSpeedFactor`, `ModelTurnSpeedFactor`, `ApplyModelSpeed`입니다.

커브 관련 속도는 하나가 아닙니다.

- **비전 커브 속도**: 모델이 본 진행 방향의 회전율과 속도로 계산
- **경로 턴 속도**: 경로·TBT에서 받은 턴 속도에 비율 적용
- **모델 미래속도**: 모델이 몇 초 뒤로 예측한 속도 사용
- **모델 주행속도 적용**: 모델의 전체 desired velocity를 크루즈 설정속도에 별도로 반영

### `AutoCurveSpeedFactor`

비전 모델의 회전율에 비율을 곱한 뒤 목표 횡가속도 1.9m/s²를 기준으로 커브 속도를 계산합니다. 값이 클수록 같은 커브를 더 굽은 것으로 보므로 목표속도가 낮아집니다.

속도 변화는 비율에 단순 반비례하지 않고 대략 제곱근 관계입니다. 예를 들어 100%에서 120%로 올리면 계산 속도는 약 `1 / √1.2`, 즉 기존의 약 91% 수준이 됩니다.

- 커브에서 너무 빠르면 한 단계 올림
- 너무 느리면 한 단계 내림

직선 오인 감속이 있으면 이 값만 보지 말고 모델·경로 중 실제로 어떤 소스가 최저속도를 선택했는지 확인하세요.

### `AutoCurveSpeedLowerLimit`

비전 커브, 경로 턴과 모델 미래속도 후보에 적용되는 최저속도입니다.

- 30이면 각 커브 후보를 최소 30km/h로 제한
- 높이면 급커브에서도 목표가 그 값 아래로 내려가지 않음
- 낮추면 더 낮은 커브 속도를 허용

이 값은 안전 최저속도를 자동으로 판단하지 않습니다. 너무 높이면 급커브 감속이 부족할 수 있습니다.

### `TurnSpeedControlMode`

| 값 | 비전 커브 | 경로 턴 |
|---:|---:|---:|
| 0 | 사용 안 함 | 사용 안 함 |
| 1 | 사용 | 사용 안 함 |
| 2 | 사용 | 턴 지점 주변에서 사용 |
| 3 | 사용 안 함 | 항상 후보에 포함 |

모드 2의 경로 속도는 현재 턴 거리 값이 약 -500~500m 범위일 때만 후보에 들어갑니다. 모드 3은 경로 속도를 항상 후보에 넣으므로 경로 정보가 부정확한 환경에서는 예상하지 못한 감속이 생길 수 있습니다.

> [!IMPORTANT]
> `TurnSpeedControlMode=0`이 모든 모델 기반 속도 기능을 끄는 것은 아닙니다. `ModelTurnSpeedFactor`와 `ApplyModelSpeed`는 별도 분기이므로 각각 0인지 확인해야 합니다.

### `MapTurnSpeedFactor`

    경로 턴 후보 = 경로 속도 × 반영비율 ÷ 100

- 80%: 경로 속도를 더 낮춰 반영
- 100%: 받은 속도 그대로
- 120%: 받은 속도보다 높게 반영

그 결과에 `AutoCurveSpeedLowerLimit`이 최저값으로 적용됩니다. 설정 설명의 APN·외부 연결 문구와 별개로, 현재 지원되는 입력에서 유효한 경로 속도가 들어와야 동작합니다. 당근맨과 CarrotLink는 현재 지원하지 않습니다.

### `ModelTurnSpeedFactor`

저장값에 `0.1초`를 곱해 모델 속도 예측에서 볼 미래 시점을 정합니다.

| 저장값 | 보는 시점 |
|---:|---:|
| 0 | 사용 안 함, 모델 턴 속도 200km/h로 비활성화 |
| 10 | 약 1.0초 뒤 |
| 30 | 약 3.0초 뒤 |
| 50 | 약 5.0초 뒤 |

선택한 시점의 모델 속도에 1.2를 곱하고 평활화한 값이 후보가 됩니다. 값이 크다고 항상 더 느려지는 설정은 아니며, 더 먼 미래에 모델이 예측한 속도가 낮은지 높은지에 따라 달라집니다.

### `ApplyModelSpeed`

이 설정은 이름과 달리 커브 전용이 아닙니다. 주행 모델의 `desiredVelocity`에 비율을 곱해 크루즈 설정속도에 반영합니다.

    모델 적용속도 = 모델 desired velocity × |설정비율| ÷ 100
    실제 상한 = 모델 적용속도와 도로 제한속도 × 110% 중 낮은 값

| 값 | 현재 코드 동작 |
|---:|---|
| 0 | 사용 안 함 |
| 양수 | 현재 설정속도가 상한보다 낮을 때만 상한까지 올림 |
| 음수 | 현재 설정속도를 계산된 상한으로 직접 바꿈 |

> [!WARNING]
> 음수는 단순히 감속만 허용하는 스위치가 아니라 설정속도를 계산값으로 계속 덮어쓰는 강한 동작입니다. 유효한 도로 제한속도가 없으면 상한이 0으로 계산될 수 있으므로 충분히 이해하지 못했다면 `0`을 유지하세요.

감속 버튼이나 브레이크로 자동 속도 증가가 일시정지되면 모델 속도 적용도 멈출 수 있습니다.

### 커브 조정 추천 순서

1. `TurnSpeedControlMode=1`, `ModelTurnSpeedFactor=0`, `ApplyModelSpeed=0`으로 비전 커브만 분리합니다.
2. `AutoCurveSpeedFactor`를 5씩 바꾸며 같은 커브에서 비교합니다.
3. 필요한 최저값만 `AutoCurveSpeedLowerLimit`로 정합니다.
4. 경로 정보가 검증된 경우에만 모드 2와 `MapTurnSpeedFactor`를 추가합니다.
5. `ModelTurnSpeedFactor`는 마지막에 추가하고, `ApplyModelSpeed`는 별도 기능으로 시험합니다.

## 5. 신호감지

관련 설정은 `TrafficLightDetectMode`, `TrafficStopDistanceAdjust`입니다. 카메라에서 신호등 색을 직접 판독하는 단순 기능이 아니라 모델이 예측한 경로 종점과 미래 속도 변화를 이용해 정지·출발 상태를 추정하고, 들어온 신호 이벤트도 함께 처리합니다.

### `TrafficLightDetectMode`

| 값 | 설정 의도 | 현재 코드에서 확인할 점 |
|---:|---|---|
| 0 | 신호감지 안 함 | 감지 상태를 강제로 끔 |
| 1 | 신호 정지만 감지 | 완전히 정지한 상태의 자동 출발을 막음 |
| 2 | 신호 정지·출발 모두 | 녹색 판단 시 출발 상태로 전환 가능 |

> [!IMPORTANT]
> 모드 1도 감속 중 녹색으로 판단되면 정지 계획을 해제하는 분기가 있습니다. 따라서 현재 코드에서 `1`을 “어떤 상황에서도 출발 판단을 전혀 사용하지 않음”으로 보장할 수 없습니다.

다음 상황에서는 신호 감지가 꺼지거나 제한됩니다.

- `MyDrivingMode=4` 고속 모드
- 조향각 절대값이 약 20도를 넘는 상황
- 모델이 정지 경로를 확신하지 못함
- 강한 일반 감속 중 오감지 방지 조건
- 선행차가 정지 목표보다 앞에 있는 상황

모델의 오인식으로 불필요한 감속이나 잘못된 출발 판단이 생길 수 있습니다. 신호 대기 중에도 운전자가 브레이크와 주변 교통을 직접 확인해야 합니다.

### `TrafficStopDistanceAdjust`

저장값을 100으로 나눈 미터 단위로 정지 장애물 위치에 더합니다.

| 저장값 | 실제 보정 | 일반적인 방향 |
|---:|---:|---|
| -200 | -2.0m | 더 일찍, 정지선에서 더 멀리 정지 |
| -150 | -1.5m | Params 최초값 |
| 0 | 0m | 모델 위치 그대로 |
| 100 | +1.0m | 더 늦게, 정지선 쪽으로 전진 |

양수는 정지 목표를 차량 진행 방향으로 더 멀리 옮겨 늦게 서게 하고, 음수는 차량 쪽으로 당겨 일찍 서게 합니다. 차량이 거의 멈춘 상태에서는 현재 코드가 사용자 값 대신 고정 -2.0m를 사용하므로 마지막 정지 위치가 설정값과 정확히 일치하지 않을 수 있습니다.

예외적으로 활성 `leadOne` 없이 E2E 정지 중일 때, 카메라 모델의 고확률 저속 차량이 계획 정지점 바로 앞 0~3m에 5프레임(약 0.25초) 연속 확인되면 이를 정지차 뒤에 생성된 정지점으로 판단합니다. 이 정지에만 일반 신호 보정값 대신 `+2.0m`를 적용해 가상 장애물을 차량 위치에 가깝게 옮기고, MPC는 `StopDistanceCarrot`만큼의 정지 차간을 다시 확보합니다. SCC나 레이더 객체를 생성하거나 `leadOne`으로 승격하는 기능은 아니며, 조건이 성립하지 않으면 기존 신호 정지 동작과 고정 -2.0m 동작을 그대로 유지합니다.

### 조정 요령

- 항상 정지선에서 너무 멀리 서면 `TrafficStopDistanceAdjust`를 100, 즉 1m씩 올립니다.
- 정지선을 넘거나 너무 늦게 서면 100씩 내립니다.
- 앞차가 있는 경우에는 위 자동 차량 기준 보정이 우선할 수 있으므로, 정지선 보정값은 앞차가 없는 신호 정지에서 비교합니다.
- 정지 위치보다 먼저 신호 오인 감속이 문제라면 보정값을 바꾸지 말고 `TrafficLightDetectMode`와 모델 판단부터 확인합니다.
- 같은 도로, 비슷한 진입 속도에서 한 번에 한 단계만 비교합니다.

## 문제 해결 빠른 표

| 증상 | 먼저 확인할 항목 |
|---|---|
| 카메라 앞에서 너무 늦게 감속 | 이벤트 거리 → `DecelRate` 낮춤 → `CtrlEnd` 높임 |
| 카메라 목표속도가 예상과 다름 | 수신 제한속도, `SafetyFactor`, 다른 최저속도 후보 |
| 제한속도 변경에 반응하지 않음 | 유효한 도로 속도, `AutoSpeedUptoRoadSpeedLimit`, `AutoRoadSpeedAdjust` 의존성 |
| 방지턱 감속이 없음 | 모드 2 이상, 이벤트 종류, 도로 범주 |
| 직선에서 커브 감속 | 최종 소스가 비전·경로·모델 중 무엇인지 확인 |
| 턴 모드 0인데 감속 | `ModelTurnSpeedFactor`, `ApplyModelSpeed`, 별도 ATC 확인 |
| 신호에서 불필요한 정지·출발 | `TrafficLightDetectMode`, 주행 모드, 모델 판단 확인 |

CAN 오류로 자동 전송되는 진단 로그는 현재 온로드에서 새로 수신 중인 차량 또는 레이더 상태가 실제 오류를 보고할 때만 생성됩니다. 이전 주행 종료 과정의 CAN timeout은 사용하지 않으며, 오류 뒤의 상황을 포함하도록 감지 5초 후 캡처합니다. 따라서 속도·감속 이상을 분석할 때 자동 진단 로그가 없더라도 필요한 주행 구간은 Carrot Web에서 별도로 전송해야 합니다.
