# CarrotAssist 사용 설명서

[English](../en/carrot-assist.md) · [Carrot Web](carrot-web.md)

CarrotAssist는 같은 네트워크의 당근 기기를 찾아 Carrot Web을 열고, 휴대폰의 기본 음성비서를 호출하는 Android 앱입니다. ChatGPT에 당근 연결을 등록하면 설정 검색·설명·화면 열기를 사용할 수 있습니다. 별도 권한을 허용하면 현재 설정값을 조회하고, 변경 전후 값을 확인한 뒤 변경할 수 있습니다.

## 준비와 설치

1. 정차한 상태에서 당근 기기를 최신 `carrot-wip`으로 업데이트하고 재시작합니다.
2. 휴대폰과 당근 기기를 같은 Wi-Fi 또는 핫스팟에 연결합니다. 신뢰하는 네트워크에서만 사용하고, 장치의 7000 포트를 인터넷에 공개하지 마세요.
3. [CarrotAssist 배포 페이지](https://github.com/ajouatom/openpilot/releases/tag/carrot-assist-v0.2.0)의 APK를 휴대폰에 설치합니다. Android가 요청하면 해당 다운로드 앱의 설치 권한을 확인합니다.
4. 공식 ChatGPT 앱을 설치하고 본인 계정으로 로그인합니다. Android 설정의 기본 디지털 어시스턴트에서 ChatGPT를 선택합니다. 메뉴 이름은 휴대폰에 따라 다릅니다.

Android 8 이상을 대상으로 하며, 실제 연결·작은 음성창 시험은 Samsung Android 17에서 진행했습니다. 다른 기종의 작은 창 동작은 다를 수 있습니다. ChatGPT 계정에는 **사용자 정의 MCP 추가** 기능이 있어야 합니다. 무료 계정의 당근 연결과 미니 음성 모드 지원은 확인되지 않았으며, 유료 계정도 계정 정책과 제공 기능을 확인해야 합니다.

## 처음 한 번 연결하기

1. CarrotAssist를 실행합니다. 처음 5초 동안 기기가 하나만 발견되면 자동으로 열고, 여러 개면 선택합니다. 없으면 약 1분 동안 검색합니다. 검색이 안 되면 기기 IPv4 주소를 직접 입력합니다.
2. 열린 웹의 **도구 > ChatGPT 설정 도우미**를 엽니다.
3. 설정값도 다루려면 정차·주행 보조 해제 상태에서 **설정값 조회·변경 허용**을 누릅니다. 요청한 설정의 현재 값과 변경 결과가 ChatGPT 및 당근 중계 서버에 전달됩니다.
4. **처음 연결하는 방법 · 다시 연결**을 펼치고 **당근 연결 주소 복사**, **ChatGPT 연결 화면 열기**를 이용합니다. 폰에 추가 메뉴가 없으면 같은 계정의 PC 웹에서 [ChatGPT 플러그인](https://chatgpt.com/plugins)을 엽니다.
5. 추가 버튼의 **사용자 정의 MCP 서버 추가**를 선택합니다. 이름은 `CarrotAssist`, 서버 URL에는 복사한 아래 주소를 붙여넣습니다. 인증 방식 목록에서는 **OAuth**를 선택하고 생성·연결합니다. OAuth는 내 ChatGPT에 당근 기기 접근을 승인하는 연결 방식의 이름입니다.

   `https://carrot-mcp.shind0.synology.me/account/mcp`

6. 당근 승인 페이지가 열리면 CarrotAssist로 돌아와 **미니모드 연결 코드 만들기**를 누르고, 나온 코드를 승인 페이지에 입력합니다. 값 조회·변경을 사용할 때는 해당 권한도 선택하고 승인합니다. 기존 화면 열기 전용 연결은 새 권한으로 다시 승인해야 합니다. 기존 플러그인에 새 기능이 보이지 않으면 ChatGPT의 플러그인 관리에서 **도구 새로 고침**을 누르고 새 대화에서 시험합니다.
7. 플러그인을 설치하고 새 대화에서 당근 설정을 검색해 봅니다. 앱으로 돌아온 뒤 오른쪽 위 마이크를 눌러 음성비서를 호출합니다.

코드의 **5분은 최초 승인에 사용할 수 있는 시간**입니다. 연결 자체가 5분 후 끝나는 것은 아닙니다. 코드는 일회용이며 만료되면 새로 만드세요. 대화창에 코드를 보내지 말고 당근 승인 페이지에만 입력하세요. 정상 승인 후에는 새 음성 대화에서도 같은 기기를 사용하므로 매번 연결을 요청하지 않아도 됩니다.

Chrome·Samsung Internet와 CarrotAssist는 웹 저장 공간이 다릅니다. 앱 안에서 한 번 승인해야 하며, 앱 삭제·데이터 초기화·기기 IP 변경 시 재연결이 필요할 수 있습니다. 연결 하나는 승인한 웹 세션 하나를 대상으로 합니다.

## 말하는 방법

| 목적 | 예시 |
|---|---|
| 설정 찾기 | “당근 도구로 깜박이 관련 설정을 찾아줘.” |
| 설명 듣기 | “첫 번째 설정은 무슨 기능이야?” |
| 화면 열기 | “차간거리 단계 설정을 열어줘.” |
| 현재 값 확인 | “당근 디바이스 화면 밝기의 현재 값을 알려줘.” |
| 변경 제안 | “그 밝기를 60으로 바꿔줘.” |
| 제안 확인 | 변경 전후 값을 듣고 “응, 그 값으로 변경해.” |

변경은 **현재 값 조회 → 변경값 제안 → 사용자 확인 → 적용 결과 확인** 순서입니다. 설명의 기본값을 현재 기기 값으로 취급하지 않습니다. 설정 범위와 변경 단위를 검사하며, 제안은 60초 후 만료됩니다. 그 사이 값이 바뀌면 다시 제안·확인해야 합니다.

ChatGPT의 플러그인 권한 설정에 따라 **한 번만 허용** 같은 도구 실행 승인 화면이 추가로 나올 수 있습니다. 승인을 기다리다 제안이 만료되면 새 제안을 확인해야 합니다. 모든 상황에서 화면 조작 없이 음성만으로 완료된다고 보장하지 않습니다.

“10% 올려줘”는 현재 값의 10%를 더하는 상대 변경입니다. 50이면 55를 제안하며, 설정의 변경 단위에 맞게 반올림될 수 있습니다. “10을 더해줘”는 10을 더합니다. 값 0에 자동 같은 특별한 의미가 있는 항목은 설명을 확인하고 명시적인 값을 요청하세요. 당근 기기 밝기인지 휴대폰 밝기인지도 구분해서 말하세요.

화면 열기와 변경 결과 전달에는 CarrotAssist의 웹 화면이 활성 상태여야 합니다. 작은 음성창 아래에 웹을 유지하세요. 전체 화면으로 다른 앱을 사용하거나 화면을 잠그면 요청이 대기하다 만료될 수 있습니다. “요청됨”은 “변경 완료”와 다릅니다.

## 지원 범위

음성 변경은 기기에 정의된 범위·단위가 있는 정수 설정을 대상으로 합니다. 화면 밝기(`ShowCustomBrightness`), 클러스터 밝기(`ClusterHudBrightness`), 알림 음량(`SoundVolumeAdjust`) 외의 변경은 최신 정차·주행 보조 해제 상태가 확인되어야 합니다. 운전자 감시 해제 등 제한된 설정은 지원하지 않습니다.

이번 버전은 실시간 크루즈 속도 변경, 차선변경 실행, 방향지시등 직접 제어, 주행 분석과 로그 업로드를 지원하지 않습니다. 튜닝 설정을 변경하는 것과 차량에 즉시 주행 명령을 내리는 것은 구분됩니다. 변경 이력에서는 음성 도우미가 변경한 항목을 확인할 수 있습니다. 재시작이 필요한 설정은 해당 설정 설명을 따르세요.

## 업데이트와 연결 해제

앱은 실행할 때 새 버전을 자동 확인합니다. 성공한 확인 이후에는 6시간 간격으로 확인하며, 상단 기기 이름을 누르면 앱 정보와 수동 확인을 열 수 있습니다. 새 버전 다운로드 후 Android 설치 화면에서 설치를 승인하세요. 같은 서명의 업데이트는 기존 연결 정보를 유지하므로 먼저 앱을 삭제하지 마세요.

처음 앱 안에서 업데이트할 때는 Android의 **출처를 알 수 없는 앱 설치 > CarrotAssist > 권한 허용** 화면이 나올 수 있습니다. 허용 후 뒤로 돌아와 **패키지 설치 프로그램 > 이번만 > 업데이트**로 진행합니다. 삼성 기기에서는 자체 배포 앱에 대한 추가 안내가 나올 수 있으니, 위 공식 배포 페이지의 CarrotAssist인지 확인하세요.

앱 업데이트, 당근 기기의 Git 업데이트, 중계 서버 업데이트는 별개입니다. 앱만 업데이트해도 오래된 기기 소프트웨어에 새 기능이 생기는 것은 아닙니다.

웹 도구의 **설정값 조회·변경 해제**로 값 접근만 해제할 수 있습니다. **연결 해제**는 이 웹 세션의 연결 권한을 취소합니다. 필요한 경우 ChatGPT에서도 플러그인 연결을 해제하세요.

## 비용과 다른 음성비서

AI 대화는 각 사용자의 ChatGPT 계정으로 처리하며 해당 계정의 사용량·제한이 적용됩니다. 현재 중계 서버는 AI 모델 API를 호출하지 않으므로 사용자 대화가 개발자의 ChatGPT·Codex 사용량을 사용하지 않습니다. 중계 서버의 네트워크와 운영 비용은 별개입니다. 이 연결은 음성 녹음이나 주행 로그를 업로드하는 기능을 제공하지 않습니다.

마이크 버튼은 Android 기본 음성비서를 호출합니다. Gemini도 호출 대상이 될 수 있지만, 당근 MCP 연결은 현재 지원으로 안내하지 않습니다. Google 공식 안내상 사용자 정의 MCP는 미국·영어·개인 계정 대상이고, Gemini Live에서 사용자 정의 MCP를 사용하는 것은 확인되지 않았습니다. 기존 Google Assistant의 App Actions는 별도 연동 방식이며 이 앱에는 구현되지 않았습니다.

공식 안내: [ChatGPT 사용자 정의 MCP](https://developers.openai.com/plugins/deploy/connect-chatgpt), [Gemini 사용자 정의 앱](https://support.google.com/gemini/answer/17209137), [Gemini Live 지원 앱](https://support.google.com/gemini/answer/15274899).
