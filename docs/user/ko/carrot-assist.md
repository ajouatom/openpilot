# CarrotAssist 사용 설명서

[English](../en/carrot-assist.md) · [Carrot Web](carrot-web.md)

CarrotAssist는 같은 네트워크의 당근 기기를 찾아 Carrot Web을 열고, 휴대폰에서 간단한 음성 명령을 처리하는 Android 앱입니다. 복잡한 질문은 기본 음성비서로 이어갈 수 있습니다. ChatGPT에 당근 연결을 등록하면 설정 검색·설명·화면 열기를 사용할 수 있습니다. 별도 권한을 허용하면 현재 설정값을 조회하고 명확히 지정한 값을 범위 검사 후 변경할 수 있습니다.

### 폰에서 직접 음성 명령 사용하기

CarrotAssist 0.2.11과 최신 당근웹에서 사용합니다. Android 12 이상이고 휴대폰에 현재 언어의 기기 내 음성 인식기가 있어야 합니다. 마이크 권한은 최초 한 번 허용하세요. 폰 직접 명령에는 ChatGPT 계정, 유료 구독, MCP 등록이 필요 없습니다. ChatGPT 무료 사용자와 MCP 등록 메뉴가 없는 사용자도 이 방식으로 쓸 수 있습니다. 연결 코드 입력은 건너뛰세요. 새로 설치하면 폰 직접 듣기가 기본입니다. 이미 쓰던 앱을 업데이트하면 기존 미니창 방식을 유지합니다. 상단 기기 이름에서 **폰에서 음성 명령 먼저 듣기**와 **당근웹 연결 시 음성조수 자동 실행**을 켜 두면 연결 후 인사하고 듣습니다. 마이크를 누르면 듣기를 종료하거나 다시 시작할 수 있습니다.

- **“가속도 설정을 찾아줘”**라고 하면 현재 기기의 관련 설정 목록을 열고, 개수와 첫 항목을 읽어줍니다. 검색에는 설정 변경 권한이 필요 없습니다.
- **“가속도 설정 0을 240으로 바꿔줘”**라고 하면 해당 항목의 저장값을 확인한 뒤 결과를 읽어줍니다. 정차하고 주행 보조를 해제한 상태에서 **당근웹 → 도구 → ChatGPT 설정 도우미 → 설정값 조회·변경 허용**을 한 번 켜세요. 이미 허용했다면 그대로 쓸 수 있습니다. 이름이 한 항목과 일치하고 지정한 정수가 허용 범위 안이면 추가 확인 없이 적용합니다. 이 항목의 범위는 1~250입니다. 음성 후보에서 숫자가 엇갈리거나 이름이 모호하면 변경하지 않습니다.
- **“가속도 설정을 찾아줘” → “첫 번째 거 240으로 바꿔줘”**처럼 이어서 말할 수 있습니다. 같은 폰 음성 세션에서 방금 보여준 목록의 순서를 사용합니다. “두 번째 거”나 “3번 항목”도 됩니다. 저장 후 실제 설정 이름과 값을 읽어줍니다. 목록이나 대화가 바뀌면 원하는 설정을 다시 검색하세요.
- **“깜박이 설정 열어줘”**는 깜박이 자동제어 설정 화면을 엽니다.
- **“왼쪽으로 차로 변경해”, “오른쪽으로 차로 변경해”**는 정차·보조 해제 상태에서 당근웹 **도구 → ChatGPT 설정 도우미 → 음성 차선변경·설정속도 명령 허용**을 한 뒤 사용할 수 있습니다. 방향 후보가 일치하고 최종 인식 신뢰도가 높을 때 한 번 요청합니다. 인식기가 신뢰도를 제공하지 않으면 “왼쪽 확인”처럼 방향을 명시한 짧은 확인이 필요합니다. 신뢰도가 낮거나 후보가 충돌하면 보내지 않습니다. 명령은 기존 차량 조건을 따릅니다.
- “가속이 왜 이렇게 빨라?” 같은 질문은 기본 음성비서를 엽니다. 기본 비서가 ChatGPT인 경우 미니창에서 질문을 다시 말하세요. 첫 발화는 ChatGPT에 전송하지 않습니다. 일반 질문에는 당근 MCP가 필요 없고, ChatGPT가 실제 당근 설정이나 차량 기능에 접근할 때에는 연결이 필요합니다.

폰 직접 듣기를 끄면 기존 미니창 방식으로 돌아갑니다. “챗GPT 열어줘”라고 하면 기본 비서를 엽니다. 처음부터 ChatGPT가 듣게 하려면 상단 기기 이름에서 **폰에서 음성 명령 먼저 듣기**를 끄세요. 미니창 차로변경에는 기존 CarrotAssist 연결과 운전 명령 권한이 필요합니다.

“왼쪽으로 차로변경”과 “오른쪽으로 차로변경”은 폰 직접 음성에서 지원합니다. 0.2.9는 양쪽 표현을 Android 13 이상 인식기에 힌트로 전달합니다. 명령을 거절할 때 받아쓴 문장이 있으면 그 문장과 이유를 말합니다. 후보 불일치, 낮은 신뢰도, 늦게 도착한 결과를 구분합니다. 실차 소음에서의 인식률은 측정하지 않았습니다.

미니창이 “당근마켓” 이야기를 하거나 차로변경을 할 수 없다고 하면, 같은 창에서 “캐럿어시스트 도구로 가속도 설정을 찾아줘”라고 해 보세요. 계정 연결은 새 대화에서도 유지되지만 미니창이 매번 CarrotAssist 도구를 선택하는 것은 보장되지 않습니다. 검색 목록이 열리는지 확인하세요.

### ChatGPT 맞춤 지침 복사하기

CarrotAssist 상단의 돋보기 옆 **기기 이름 → ChatGPT 맞춤 지침 복사**를 누르세요. 휴대폰 언어에 맞는 문구가 복사되고 붙여넣는 순서가 표시됩니다.

ChatGPT 앱에서 **메뉴 → 프로필**을 열고 설정 목록을 아래로 스크롤하세요. **ChatGPT 맞춤 설정 → 성격 → 사용자 지정 지침** 입력칸에 붙여넣고 **오른쪽 위 저장**을 누르세요. 기존 지침이 있으면 그 아래에 추가하세요. 새 대화에서 “가속도 설정을 찾아줘”로 확인할 수 있습니다. 이 문구는 ChatGPT가 ‘당근’을 당근파일럿으로 해석하도록 돕습니다. ChatGPT에서 CarrotAssist 도구를 사용하려면 기존 계정 연결과 해당 권한이 필요합니다.

## 준비와 설치

1. 정차한 상태에서 당근 기기를 최신 `carrot-wip`으로 업데이트하고 재시작합니다.
2. 휴대폰과 당근 기기를 같은 Wi-Fi 또는 핫스팟에 연결합니다. 신뢰하는 네트워크에서만 사용하고, 장치의 7000 포트를 인터넷에 공개하지 마세요.
3. [CarrotAssist 배포 페이지](https://github.com/ajouatom/openpilot/releases/tag/carrot-assist-v0.2.11)의 APK를 휴대폰에 설치합니다. Android가 요청하면 해당 다운로드 앱의 설치 권한을 확인합니다.
4. **ChatGPT 미니창도 쓸 때만** 공식 ChatGPT 앱을 설치하고 본인 계정으로 로그인합니다. Android 설정의 기본 디지털 어시스턴트에서 ChatGPT를 선택합니다. 메뉴 이름은 휴대폰에 따라 다릅니다.

Android 8 이상을 대상으로 하며, 실제 연결·작은 음성창 시험은 Samsung Android 17에서 진행했습니다. 다른 기종의 작은 창 동작은 다를 수 있습니다. ChatGPT 미니창에서 당근을 제어하려면 계정에 **사용자 정의 MCP 추가** 기능이 있어야 합니다. 무료 계정의 당근 연결과 미니 음성 모드 지원은 확인되지 않았으며, 유료 계정도 계정 정책과 제공 기능을 확인해야 합니다.

## ChatGPT로 당근을 제어할 때 처음 한 번 연결하기

**코드는 당근앱에서 복사하고, ChatGPT가 연 ‘이 기기 연결 승인’ 웹페이지에 넣습니다. 음성 대화창이나 미니모드 대화에 보내는 코드가 아닙니다.**

### 1. 당근앱에서 준비

1. CarrotAssist를 실행합니다. 처음 5초에 기기 하나가 발견되면 자동으로 열고, 여러 개면 선택합니다. 없으면 약 1분간 검색합니다. 검색이 안 되면 기기 IPv4 주소를 직접 입력합니다.
2. **도구 → ChatGPT 설정 도우미**를 엽니다. 정차·주행 보조 해제 상태에서 필요한 기능의 허용 버튼을 누릅니다. 설정값, 운전 명령, 도구 작업은 각각 별도입니다.
3. **처음 연결하는 방법 · 다시 연결**을 펼칩니다. **아직 코드를 만들지 마세요.** 아래에서 본인에게 맞는 경로로 승인 페이지부터 엽니다.

### -A. ChatGPT에 CarrotAssist가 이미 설치되어 있다면

**ChatGPT 플러그인 화면 열기 → 설치됨 → CarrotAssist → 다시 연결** 순서입니다. 기존 이름이 ‘당근파일럿 미니 음성’이면 그 항목을 선택합니다. ‘연결된 계정’ 아래에 **다시 연결**이 나올 수 있습니다. 새 플러그인을 만들 필요는 없습니다.

코드 입력칸과 **이 기기 연결 승인** 버튼이 있는 페이지가 열렸다면 3번으로 갑니다. 인기·생산성 등의 목록만 보이면 먼저 **설치됨**을 선택하세요.

### 2-B. 처음 설치하는 사람이라면

1. **처음 등록하는 경우만 펼치기**를 열어 **처음 등록할 때: 당근 연결 주소 복사**를 누르고 **ChatGPT 플러그인 화면 열기**를 누릅니다. 폰에 추가 메뉴가 없으면 같은 계정의 PC에서 [ChatGPT 플러그인](https://chatgpt.com/plugins)을 엽니다.
2. **＋ → 사용자 정의 MCP 서버 추가**를 선택하고 아래처럼 입력합니다.

   | 항목 | 입력할 내용 |
   |---|---|
   | 이름 | `CarrotAssist` |
   | 서버 URL | `https://carrot-mcp.shind0.synology.me/account/mcp` |
   | 인증 방식 | 목록에서 **OAuth** 선택 |

   OAuth는 여기서 고르는 연결 방식의 이름입니다. 사용자가 별도의 서버나 유료 API 키를 준비하는 절차가 아닙니다.
3. 만들기·연결을 진행합니다. 코드 입력칸과 **이 기기 연결 승인** 버튼이 있는 페이지가 열리면 다음으로 갑니다. 실제 메뉴 제공 여부는 계정에 따라 다릅니다. MCP 추가가 없는 계정에서 사용할 수 있다고 보장하지 않습니다.

### 3. 열린 승인 페이지에 새 코드 넣기

1. 승인 페이지는 그대로 두고 **CarrotAssist 앱으로 돌아옵니다.** 같은 설정 도우미에서 **승인 페이지를 연 뒤: 새 코드 만들기 → 승인 페이지에 넣을 코드 복사**를 누릅니다.
2. **방금 열어 둔 승인 웹페이지로 돌아가** 코드 입력칸에 붙여넣습니다. 설정값·운전 명령·도구 실행 중 사용할 권한을 선택하고 **이 기기 연결 승인**을 누릅니다. 앱에서 허용한 기능도 이 페이지에서 승인해야 합니다.
3. ChatGPT로 돌아오면 연결을 확인합니다. 앱의 도우미 상태가 **계정 연결됨**으로 바뀌는지도 확인하세요. 처음 등록했다면 플러그인 설치를 마칩니다. 새 기능의 도구가 보이지 않으면 플러그인 관리의 **도구 새로고침** 후 새 대화에서 시험합니다.
4. 당근앱을 띄운 채 마이크로 “당근 도구로 깜박이 설정 하나 찾아서 열어줘”라고 시험합니다. 처음에는 설정 조회·화면 열기부터 확인하세요.

**5분은 새 코드를 입력할 수 있는 시간입니다. 연결이 5분마다 끊기는 것이 아닙니다.** 정상 연결 후 새 음성 대화마다 코드를 넣을 필요는 없습니다. 코드 생성은 복사와 다릅니다. 새로 만들면 이전 코드는 즉시 무효가 되고, 승인한 코드는 다시 사용할 수 없습니다.

| 보이는 화면·오류 | 다음 행동 |
|---|---|
| ChatGPT 대화나 작은 음성창 | 코드 입력 위치가 아닙니다. 플러그인 → 설치됨 → CarrotAssist → 다시 연결로 갑니다. |
| Google Play | 앱 설치 버튼을 누른 것입니다. 당근앱으로 돌아와 **ChatGPT 플러그인 화면 열기**를 누릅니다. |
| 유효하지 않거나 만료된 코드 | **다시 연결**로 승인 페이지를 새로 연 뒤, 당근앱에서 새 코드 한 개를 만들어 즉시 붙여넣습니다. 계속 실패하면 반복 생성하지 말고 오류 문구를 알려주세요. 코드 자체는 공유하지 마세요. |
| 연결됨인데 기기 오프라인 | 당근 기기와 폰의 인터넷·같은 네트워크를 확인하고 CarrotAssist를 화면에 띄웁니다. 코드 재발급부터 할 필요는 없습니다. |
| 도구 권한 없음 | 당근앱의 해당 허용 버튼과 ChatGPT **다시 연결**의 해당 권한 선택을 모두 확인합니다. |

Chrome·Samsung Internet와 CarrotAssist는 저장 공간이 다릅니다. **실제로 사용할 CarrotAssist 앱에서 만든 코드**를 쓰세요. 앱 삭제·데이터 초기화 시 재연결이 필요할 수 있습니다. 메뉴 이름은 계정·언어·앱 버전에 따라 달라질 수 있습니다.

### 4. 같은 변경을 매번 승인하지 않으려면

당근 설정창에서 기능을 허용해도 **ChatGPT 자체의 실행 승인 설정은 별개**입니다. 반복 승인을 원하지 않는 사용자는 최초 연결 후 다음을 직접 선택합니다.

1. 당근 설정 도우미의 **연결 후 한 번: ChatGPT 반복 승인 설정 → ChatGPT 승인 설정 열기**를 누릅니다. 또는 [ChatGPT 플러그인 설정](https://chatgpt.com/settings/plugins-settings)을 엽니다.
2. **CarrotAssist → 권한 → 모두 허용**을 선택합니다. 영어 표시는 **Permissions → Allow all actions**입니다. 다른 플러그인의 기본 설정은 바꿀 필요가 없습니다.
3. 새 음성대화에서 명확한 설정 변경 명령을 시험합니다. 예전의 재확인 안내가 남아 있으면 CarrotAssist 플러그인의 **도구 새로 고침** 후 새 대화를 시작하세요.

이 선택은 한 설정만이 아니라 **CarrotAssist에 허용된 작업 전체**에 적용됩니다. 이후 별도 연결 승인으로 다른 기능을 추가하면 그 기능도 이 플러그인 정책을 따릅니다. 기기의 범위 검사·권한 검사와 유지보수 작업의 확인 절차는 유지됩니다. 각 사용자 본인의 ChatGPT 계정에서 선택해야 하며, 당근앱은 자동 선택하거나 선택 여부를 읽을 수 없습니다. 연결 코드를 다시 만드는 절차가 아닙니다. 회사 정책이나 계정에 따라 선택지가 없을 수 있습니다.

2026-11-07 시험에서는 예전 도구 설명을 새로 고친 뒤에도 ChatGPT 자체 승인 카드가 남았습니다. CarrotAssist만 **모두 허용**으로 선택하고 새 대화에서 요청하자, 추가 승인 없이 가속도설정 0이 240 → 250으로 저장됐으며 별도 실제값 조회도 250을 확인했습니다.

### 웹을 터치하면서 음성대화하기

CarrotAssist 0.2.4에서는 주황색 마이크를 끌어 원하는 곳에 놓으면 위치가 저장됩니다. 짧게 누르면 화면에 열린 당근웹의 계정 연결과 온라인 상태를 확인한 뒤 미니 음성창을 엽니다. 실패하면 ‘다시 확인’을 누르거나 ‘음성비서만 열기’를 선택할 수 있습니다. 휴대폰 측면 버튼으로 직접 호출할 때는 이 앱의 시작 검사를 거치지 않습니다.

상단 기기 이름에서 **당근웹 연결 시 음성조수 자동 실행**을 켜면 연결될 때 한 번 안전 운전 인사를 하고 미니 음성창을 엽니다. 0.2.5부터 기기에 새 Git 업데이트가 확인되면 “당근 기기에 새 업데이트가 있어요”라고만 안내합니다. 답할 필요가 없습니다. 마이크를 직접 누르면 시작 인사를 건너뜁니다.

시작 인사는 당근웹의 계정 연결과 온라인 상태를 확인했다는 뜻입니다. 새 ChatGPT 미니 대화가 CarrotAssist 도구를 사용했는지는 답변의 도구 표시로 확인할 수 있습니다. 일반 답변만 나왔다면 정차 후 “CarrotAssist로 마지막 운전 요청 상태만 알려줘”라고 물어보세요. 상태 조회는 차로변경을 실행하지 않습니다.

CarrotAssist 0.2.5와 최신 당근웹에서 도구 권한을 허용했다면 미니창에 **“네이버지도 띄워줘”**라고 말하세요. 휴대폰에 설치한 네이버지도 앱이 열립니다.

작은 음성창에서 웹을 터치할 때 대화까지 끝난다면 다음 경로를 사용하세요.

1. ChatGPT의 **설정 → 음성 → 백그라운드 대화**를 켭니다.
2. **전체 ChatGPT 앱에서 음성대화를 시작**합니다.
3. 음성 종료 버튼 대신 **홈 버튼**으로 나와 **CarrotAssist**를 엽니다. 당근앱의 마이크를 다시 누를 필요는 없습니다.
4. 당근웹 설정을 터치하면서 말을 해 대화가 이어지는지 확인합니다.

시험 폰에서는 백그라운드 대화가 이미 켜져 있어도 작은 창 경로에서는 대화가 끝난다고 보고됐습니다. 전체 앱 경로에서는 웹 탭을 터치한 뒤에도 음성 표시가 유지됐고, 사용자가 실제 답변을 확인했습니다. 상단 초록색 ChatGPT 표시는 이 폰의 실행 표시이며 기종·버전별 모양은 다릅니다. 당근앱은 ChatGPT 음성창 높이를 하단 1/3로 제한하거나 실제 듣기 상태를 직접 읽을 수 없습니다. 연결됨 표시는 기기 연결이지 마이크 실행 표시가 아닙니다.

### 사무실 Wi-Fi와 차량 핫스팟을 바꿔 사용할 때

앱 **0.2.2**과 중계 서버 **0.7.1**부터는 최초 연결 후 **지금 앱에서 연 당근웹**을 ChatGPT가 사용합니다. IP가 바뀌거나 다른 당근 기기를 선택해도 연결 코드를 다시 입력하지 않습니다. 이전과 같은 기기인지 확인하는 절차는 없습니다. 여러 기기가 검색되면 원하는 기기를 선택하세요. 앱으로 돌아왔을 때 이전 주소에 접속할 수 없으면 다시 검색합니다.

설정 변경·운전 명령·도구 작업은 **현재 당근웹에서 허용한 권한**을 따릅니다. 최신 기기 코드에는 IP 변경 뒤 기존 로컬 권한을 복구하는 기능도 있습니다. 다른 기기에서 아직 허용하지 않은 기능은 해당 당근웹에서 허용해야 합니다. 이전 기기가 아니거나 권한 복구를 못 해도 계정 연결과 화면 열기는 진행합니다. 주소 전환 전에 남은 명령은 재실행하지 않습니다.

기존 사용자는 앱 상단 기기 이름을 눌러 **업데이트 확인**을 진행하세요. 앱은 삭제하지 마세요. 로컬 권한 복구까지 사용하려면 당근 기기도 정차 후 GitPull·재시작합니다. 0.2.1에서 이전 IP의 저장 정보를 찾지 못하던 경우를 0.2.2에서 수정했습니다. 실제 폰에 업데이트한 뒤, 기기 GitPull이나 새 코드 입력 없이 기존 핫스팟 주소의 연결을 사무실 주소로 복구하고 설정 화면 열기 완료를 확인했습니다. 주행 명령이나 설정값 변경을 시험한 것은 아닙니다.

## 영어 사용

앱0.2.2의 검색·연결·업데이트 안내는 휴대폰 언어가 한국어이면 한국어, 그 외에는 영어로 표시합니다. 당근웹은 자체 언어 설정을 따르므로 영어 사용자는 당근웹 언어도 English로 선택하세요. 중계 서버0.7.2의 연결 승인 페이지는 브라우저 언어에 맞춰 한국어·영어를 표시하며, AI는 사용자가 말한 언어로 답하도록 안내합니다.

“Find the screen brightness setting and open it”처럼 영어로 질문할 수 있습니다. 영어 검색 결과·영문 승인 페이지·영문 앱 검색 화면을 시험했습니다. 실제 영어 음성 인식과 억양별 정확도는 아직 별도로 검증하지 않았습니다. 설정 ID는 번역하지 않으며, 속도 명령의 단위는 km/h입니다.

## 말하는 방법

| 목적 | 예시 |
|---|---|
| 설정 찾기 | “당근 도구로 깜박이 관련 설정을 찾아줘.” |
| 설명 듣기 | “첫 번째 설정은 무슨 기능이야?” |
| 화면 열기 | “차간거리 단계 설정을 열어줘.” |
| 현재 값 확인 | “당근 디바이스 화면 밝기의 현재 값을 알려줘.” |
| 값 변경 | “그 밝기를 60으로 바꿔줘.” → 저장 확인 후 “60으로 변경했어요.” |

중계 서버 **0.7.3**부터 대상과 값·증감량이 명확한 변경 명령은 그 자체를 승인으로 봅니다. 내부적으로 **현재값·범위 검사 → 저장 → 저장값 확인**을 수행하고, 같은 값을 다시 묻지 않습니다. “가속도설정 0을 240으로 변경해”라고 하면 범위 안에서 240을 적용한 뒤 결과만 짧게 안내합니다. 대상이나 값이 모호하거나 AI가 추천한 값을 적용할 때만 확인합니다. 범위 밖이면 변경하지 않고 허용 범위를 알려줍니다.

내부 변경 준비는 60초 유효하며, 그 사이 현재값이나 정의가 바뀌면 저장을 거절합니다. 실패·만료·결과 미확인 요청은 자동 재실행하지 않습니다. ChatGPT 자체의 **한 번만 허용** 같은 도구 승인 화면은 별개로 나타날 수 있습니다. 이 화면은 당근 연결 코드나 새 권한 등록을 뜻하지 않습니다.

조회 자체에는 변경 확인이 필요 없습니다. 최신 당근웹은 다른 같은 주소의 창에서 변경한 로컬 권한을 요청마다 다시 읽고, 읽기 전용 코드 칸에 초점이 있어도 설정 요청을 처리합니다. 실제 편집 중에는 값 변경을 기다리지만 조회는 가능합니다. 웹 수정은 기기를 GitPull한 뒤 당근웹을 새로 열면 반영됩니다. 폰 APK는 0.2.2를 유지합니다.

“10% 올려줘”는 현재 값의 10%를 더하는 상대 변경입니다. 50이면 55로 변경하며, 계산 결과가 소수이면 가장 가까운 정수로 반올림합니다. “10을 더해줘”는 10을 더합니다. 값 0에 자동 같은 특별한 의미가 있는 항목은 설명을 확인하고 명시적인 값을 요청하세요. 당근 기기 밝기인지 휴대폰 밝기인지도 구분해서 말하세요.

화면 열기와 변경 결과 전달에는 CarrotAssist의 웹 화면이 활성 상태여야 합니다. 작은 음성창 아래에 웹을 유지하거나, 위 백그라운드 대화 방법으로 당근웹을 화면에 띄우세요. 전체 화면으로 다른 앱을 사용하거나 화면을 잠그면 요청이 대기하다 만료될 수 있습니다. “요청됨”은 “변경 완료”와 다릅니다.

## 지원 범위

음성 변경은 기기에 정의된 범위·단위가 있는 정수 설정을 대상으로 합니다. 지원하는 주행 관련 설정도 주행 중에도 명확한 명령으로 변경할 수 있습니다. 최초 권한 허용만 정차·주행 보조 해제 상태가 필요합니다. 저장 후 실제 반영 시점은 각 설정의 기존 동작을 따르며, 재시작이 필요한 설정도 있습니다. “240으로 변경”처럼 정수를 지정하면 범위 안에서 그 값을 그대로 사용합니다. 증감 버튼 단위가 5이고 최솟값이 1이어도 240을 241로 바꾸지 않습니다. 상대 변화로 소수가 나오면 가장 가까운 정수로 반올림합니다. 운전자 감시 해제 등 제한된 설정은 지원하지 않습니다.

변경 이력에서는 음성 도우미가 변경한 설정을 확인할 수 있습니다. 재시작이 필요한 설정은 해당 설정 설명을 따르세요. 방향지시등 직접 제어, 주행 분석과 주행 기록 업로드는 지원하지 않습니다. 별도 도구 권한으로 tmux 진단 로그 전송 요청은 지원합니다.

## 같은 대화에서 운전 명령 사용하기 — 시험 기능

명확한 “좌측차로변경”, “우측차로변경”은 사전 안내나 별도 상태 조회 없이 운전 요청을 먼저 보내도록 구성되어 있습니다. 요청 후 진행·완료·실패를 구분해 짧게 안내합니다. 방향이 없는 “차로변경해”는 좌우만 확인합니다. ChatGPT의 음성 인식·모델 판단·네트워크 시간은 남으며 즉시 실행이나 일정한 응답시간을 보장하지 않습니다.

중계 서버는 명령을 접수하면 바로 당근웹에 전달을 시도합니다. 첫 응답은 잠깐(최대 약 0.4초) 기기 응답을 기다립니다. 아직 응답이 없으면 “왼쪽 차로변경 요청을 접수했어요”라고 안내하고, 이후 “결과는?”이라고 물으면 최신 상태를 조회합니다. 실제 완료는 차량 결과로 확인합니다.

중계 서버 0.6.0과 해당 기기 코드가 필요합니다. 폰 APK는 0.2.0을 그대로 사용합니다. 기기를 GitPull한 뒤 정차·보조 기능 해제 상태에서 전체 재시작하세요. 웹 서버만 재시작하면 차량 제어 코드에는 반영되지 않습니다. 이 기능은 PC의 제어기·연결 시험을 거쳤으며, 실제 도로에서 음성 명령으로 주행한 검증은 아직 하지 않았습니다.

1. CarrotAssist 안의 **도구 > ChatGPT 설정 도우미 > 음성 차선변경·설정속도 명령 허용**을 선택합니다. 최초 허용은 정차·보조 기능 해제 상태에서만 가능합니다.
2. ChatGPT의 CarrotAssist 연결을 새 권한으로 다시 승인하고, 당근 승인 화면에서 **음성 차선변경·설정속도 명령 허용**을 선택합니다. 설정 변경 권한만으로는 운전 명령을 실행하지 않습니다. 연결 코드가 필요하면 앱에서 새로 만들어 승인 화면에 입력합니다.
3. 기존 마이크 버튼으로 음성대화를 한 번 시작합니다. “가속 설정 설명해줘”처럼 대화하다가 “왼쪽으로 차선변경해”라고 말할 수 있습니다. 명령마다 버튼을 누르거나 대화 모드를 바꾸지 않습니다. 작은 음성창 아래에 당근웹을 유지하세요.

| 말하기 | 처리 |
|---|---|
| “왼쪽으로 차선변경해” / “오른쪽으로 차선변경해” | 기존 차선변경 제어기에 한 차선 이동 요청 |
| “속도 올려” | 리모컨 RES/+ 한 번과 같은 설정속도 처리 |
| “속도 10 내려” | 현재 설정속도에서 10 km/h 감소 |
| “속도 내려” | 기존 음성명령 기준으로 설정속도 10 km/h 감소 |
| “속도 100으로” | 설정속도를 100 km/h로 지정 |

좌우 음성 차로변경은 기존 차로변경 조건을 따릅니다. 준비 중 옆 차로가 막히거나 사각지대가 감지되면 시작하지 않습니다. **깜박이 자동제어 2**에서 외부 깜박이 장치가 응답하면 차로변경을 시작하는 시점에 같은 방향의 깜박이도 요청합니다. 장치 응답이 늦거나 송신에 실패해도 차로변경은 진행될 수 있습니다. 지원되는 순정 자동 방향지시등 경로에서는 기존과 같이 점등을 먼저 확인합니다.

명확한 실행 명령에는 별도의 “변경할까요?” 대화를 붙이지 않습니다. 저장 설정도 명확한 대상·값 명령이면 내부 검증 후 재질문 없이 적용합니다. ChatGPT 자체 도구 승인창은 별도로 나올 수 있어 모든 계정에서 완전한 무버튼 실행을 보장하지 않습니다. 음성 인식·ChatGPT 판단·네트워크 지연도 있으므로 긴급 조작 수단으로 쓰지 않습니다.

차선변경은 주행 보조·속도·차선·사각지대·기존 운전자 토크 조건 등을 확인합니다. 운전자 조작, 다른 주행 요청, 오래된 차량 상태가 있으면 거절할 수 있습니다. 속도 명령은 이미 종방향 제어가 활성화된 지원 구성에서만 처리하며 주행 보조를 새로 켜지 않습니다. PCM 속도를 그대로 따르는 구성에서는 거절할 수 있습니다. 설정속도 변경은 실제 차량 속도가 이미 그 값에 도달했다는 뜻이 아닙니다.

전달은 5초, 기기에서 소비할 명령은 1초 이내의 새 요청이어야 합니다. 차선변경 시작 조건이 3초 안에 충족되지 않으면 대기를 취소합니다. 한 번에 하나의 운전 요청만 처리하며, 중복 실행 방지를 위해 직전 요청 후 10초 이내의 같은 요청은 결과를 다시 보여주고 다른 요청은 거절할 수 있습니다. 만료·실패·응답 미확인 후 자동 재실행하지 않습니다. “앞차가 있으니 천천히 가”처럼 목표가 모호한 말은 필요한 값을 물으며 레이더에 차가 잡힐 때까지 임의로 계속 감속하지 않습니다.

“변경 중”과 “완료”를 구분합니다. 차선변경 완료는 제어기의 종료와 차선 통과 관측이 함께 확인된 경우에만 안내합니다. **음성 운전 명령 허용 해제**는 새 명령과 아직 시작하지 않은 요청을 막습니다. 이미 진행 중인 조향을 강제로 취소하는 버튼은 아닙니다. 현재 Bluetooth 리모컨에는 폰 음성대화 시작 기능을 추가하지 않았습니다.

## 도구 버튼을 음성으로 사용하기

중계 서버 0.7.0과 해당 기기 코드가 필요합니다. 폰 앱은 0.2.0을 그대로 사용합니다. 기기를 GitPull하고 재시작한 뒤 당근웹을 새로 여세요. **도구 > ChatGPT 설정 도우미 > 도구 화면·작업 실행 허용**을 누르고, 위 ‘이미 설치한 경우’ 순서로 ChatGPT를 다시 연결해 **도구 화면·작업 실행 허용**도 선택합니다. 기존 설정·운전 권한에 자동으로 추가되지 않습니다.

| 예시 | 처리 |
|---|---|
| “블루투스 설정 열어줘”, “기기 정보 보여줘” | 해당 선택창을 엽니다. 차량 선택·언어·웹 설정·브랜치·Git 기록·설정 보기·QR 백업도 지원합니다. |
| “GitPull 해줘” | 업데이트 영향을 설명하고 확인 후 기존 GitPull 작업을 시작합니다. 재시작은 별도 요청입니다. |
| “기기 재시작해줘”, “전체 재빌드해줘” | 확인 후 요청합니다. 재빌드·캘리브레이션 초기화는 재시작을 포함합니다. |
| “설정 백업해줘” | 확인 후 기기에 백업 파일을 만듭니다. 폰 다운로드는 도구 화면에서 진행합니다. |
| “tmux 진단 로그 서버에 보내줘” | 전송 내용을 확인받고 기존 당근 업로드 서버로 전송을 요청합니다. 주행 기록 파일 업로드와는 별개입니다. |
| “진단 로그 저장해줘” | 서버 전송 없이 기기에 tmux 로그를 저장합니다. |
| “화면 녹화 켜줘 / 꺼줘” | 확인 후 화면 녹화 설정을 지정합니다. 실제 녹화 파일 생성 완료로 안내하지 않습니다. |
| “화면 녹화 전부 삭제해줘”, “주행 로그 전부 삭제해줘” | 전체 삭제 범위를 안내하고 확인 후 실행합니다. 되돌릴 수 없습니다. |
| “설정 복원 열어줘” | 해당 버튼을 보여줍니다. 파일 선택·QR 읽기·클립보드 복사·저장소 초기화는 폰에서 직접 진행합니다. |

Git Sync와 HEAD 기준 hard/mixed/soft reset도 확인 후 실행할 수 있습니다. 임의 셸 명령, URL·파일 경로, 임의 커밋·브랜치 변경을 음성 작업에 넘기지 않습니다. 브랜치와 Git 기록의 실제 선택은 열린 화면에서 합니다. eGPU 화면 열기는 지원하지만 모델 변경·컴파일 재시작을 자동 실행하지 않습니다.

화면 녹화 외 실행 작업은 정차·주행 보조 해제 상태에서 준비·실행합니다. **“준비됨”은 아직 실행 전**, **“작업 중”은 완료 전**입니다. 재시작·재빌드·보정 초기화·로그 전송은 **요청 접수**와 실제 재시작·업로드 완료를 구분합니다. 불명확한 결과나 연결 끊김 뒤에는 자동 재실행하지 않습니다. 앱의 도구 작업 이력에서 자세한 결과를 확인하세요. 권한 해제는 새 요청과 아직 실행하지 않은 제안을 막으며 이미 시작한 작업을 중단하지는 않습니다.

ChatGPT에는 작업 종류와 간단한 결과만 전달합니다. 진단 로그 원문·설정 백업 파일을 ChatGPT로 보내지 않습니다. 진단 전송 시에는 기존 업로드 서버에 차량 식별정보와 진단 내용이 포함될 수 있습니다. 실제 차량의 삭제·재시작·업로드를 실행하는 시험은 하지 않았습니다.

## 업데이트와 연결 해제

앱은 실행할 때 새 버전을 자동 확인합니다. 성공한 확인 이후에는 6시간 간격으로 확인하며, 상단 기기 이름을 누르면 앱 정보와 수동 확인을 열 수 있습니다. 새 버전 다운로드 후 Android 설치 화면에서 설치를 승인하세요. 같은 서명의 업데이트는 기존 연결 정보를 유지하므로 먼저 앱을 삭제하지 마세요.

처음 앱 안에서 업데이트할 때는 Android의 **출처를 알 수 없는 앱 설치 > CarrotAssist > 권한 허용** 화면이 나올 수 있습니다. 허용 후 뒤로 돌아와 **패키지 설치 프로그램 > 이번만 > 업데이트**로 진행합니다. 삼성 기기에서는 자체 배포 앱에 대한 추가 안내가 나올 수 있으니, 위 공식 배포 페이지의 CarrotAssist인지 확인하세요.

앱 업데이트, 당근 기기의 Git 업데이트, 중계 서버 업데이트는 별개입니다. 앱만 업데이트해도 오래된 기기 소프트웨어에 새 기능이 생기는 것은 아닙니다.

웹 도구의 **설정값 조회·변경 해제**로 값 접근만 해제할 수 있습니다. **연결 해제**는 이 웹 세션의 연결 권한을 취소합니다. 필요한 경우 ChatGPT에서도 플러그인 연결을 해제하세요.

## 비용과 다른 음성비서

AI 대화는 각 사용자의 ChatGPT 계정으로 처리하며 해당 계정의 사용량·제한이 적용됩니다. 현재 중계 서버는 AI 모델 API를 호출하지 않으므로 사용자 대화가 개발자의 ChatGPT·Codex 사용량을 사용하지 않습니다. 중계 서버의 네트워크와 운영 비용은 별개입니다. 음성 녹음과 주행 기록 업로드는 지원하지 않습니다. 별도 도구 권한을 허용하고 확인한 경우 tmux 진단 로그 전송을 요청할 수 있습니다.

마이크 버튼은 Android 기본 음성비서를 호출합니다. Gemini도 호출 대상이 될 수 있지만, 당근 MCP 연결은 현재 지원으로 안내하지 않습니다. Google 공식 안내상 사용자 정의 MCP는 미국·영어·개인 계정 대상이고, Gemini Live에서 사용자 정의 MCP를 사용하는 것은 확인되지 않았습니다. 기존 Google Assistant의 App Actions는 별도 연동 방식이며 이 앱에는 구현되지 않았습니다.
