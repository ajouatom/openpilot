# 깜빡이 제어 장치: 지원 목록과 설치 안내

장치를 선택하면 사진, 배선, 펌웨어 설치와 확인 방법이 나옵니다. 처음 만드는 분은 납땜이 필요 없는 **CANable 2.0 + PC 설치 방법**부터 보세요. USB CAN 장치는 젯슨에 연결하며, S3는 콤마의 BLE에 연결합니다.

| 장치와 설명서 | 연결 방법 | 지원 범위 |
|---|---|---|
| **[CANable 2.0 설치하기](canable.md)** | CANable → 젯슨 USB | MKS V2.0 / V2.0 S 기본형의 STM32G431·호환 DFU 구성. Carrot 전용 펌웨어 필요. 좌·우 실차 점멸 확인. |
| **[S3 BLE 장치 만들기](s3-can.md)** | S3 → 콤마 BLE | ESP32-S3 DevKitC-1 N16R8 + SN65HVD230 3.3 V. 보드 사이 네 가닥 납땜 필요. |

## 여러 장치를 꽂으면

S3·PEAK·CANable 중 **먼저 정상 연결과 대상 CAN을 확인한 장치 하나**가 제어를 맡습니다. S3 등록 정보가 있다는 이유만으로 USB 장치를 막지 않습니다. 나중에 다른 장치를 꽂아도 정상 작동 중인 장치를 빼앗지 않습니다.

선택한 장치가 끊기거나 대상 CAN을 잃으면 제어를 멈추고 다음 사용 가능한 장치를 찾습니다. 이전 장치의 명령이 만료되도록 전환 대기 시간이 있으며, 진행 중이던 명령을 다른 장치로 복사해 중복 실행하지 않습니다. 전환은 무중단이 아닙니다. 별도 차량 기능인 **CAN-FD SPAS**를 켜면 해당 기존 차량 제어 경로를 사용합니다.

## 차량 지원은 별도로 확인하세요

USB 장치가 인식된다는 것과 해당 차량의 깜빡이를 제어할 수 있다는 것은 다릅니다. 현재 PEAK/CANable 제어 프로필은 **아이오닉 5 PE에서 확인한 500 kbit/s 클래식 CAN의 0x3C1·0x413**을 사용합니다. S3도 해당 메시지의 형식·상태·CRC 조건을 확인하며, 주소 숫자만 같다고 모든 차량에 호환되는 것은 아닙니다.

차량에 맞는 CAN H/L 연결점이 확인되어 있어야 합니다. OBD 커넥터나 E-CAN/C-CAN이라는 이름만 보고 핀을 정하지 마세요. 순정 레버의 동작을 먼저 확인한 뒤 P단 정차 상태에서 좌·우를 시험합니다.

## 이번 설치 도구가 지원하지 않는 제품

CANable V1.0, MCU가 다른 복제품, CANable Pro, PCAN-USB FD/Pro와 다른 USB CAN 제품은 이 설치 파일의 지원 대상으로 확인하지 않았습니다. 이름이나 케이스가 비슷하다는 이유로 펌웨어를 넣지 마세요. CANable 사진의 아래쪽 **Pro** 모델은 부품 위치를 비교하는 참고 사진입니다.
