# 운전자 감시

`DriverMonitoringMode`는 `0: 기본`이 기본값이며, `1: 실험 모드`를 별도로 선택할 수 있습니다. 변경 후 기기를 재부팅하세요. 기존 `DisableDM` 값은 실험 모드로 승계하지 않습니다.

> [!CAUTION]
> 실험 모드는 법규에 위배될 수 있으므로 통제된 시험 환경에서 실험 목적으로만 사용하세요. 공도 사용의 적법성·안전성이나 국가별 인증을 보장하지 않습니다. 0번의 콤마 기본 기준도 모든 국가의 법적 허용 한도를 의미하지 않습니다.

## 카메라를 사용할 수 있을 때

0번은 콤마의 얼굴·고개 방향·눈 감김·졸음·휴대전화 감지 및 경고 기준을 사용합니다. 1번은 고개 방향 허용 폭을 20% 넓힙니다. 눈 감김·졸음·휴대전화 감지 기준과 최고 단계 경고 후의 기존 처리는 유지합니다.

1번에서는 새로운 페달·핸들·차량 버튼·BT 버튼 조작이 있으면 일반 주의분산 대기시간을 조작당 최대 2초 회복합니다. 추가 회복은 1초에 한 번 이하이며 정상 상태 이상으로 시간을 적립하지 않습니다. 주황색·최고 단계 경고, 눈 감김·졸음·휴대전화 감지 및 해당 감지로 남은 주의분산에는 이 추가 회복을 적용하지 않습니다.

얼굴 방향과 양쪽 눈의 검출 신뢰도, 눈 감김·졸음·휴대전화·선글라스 확률을 조합한 전방주시 지표가 0.9 이상으로 2초간 이어지면 일반 주의분산의 회복 속도가 1.5배가 됩니다. 이 지표는 전방주시나 각성을 보증하는 확률이 아닙니다. 이 추가 회복도 1번에서만 적용하며 주황색·최고 단계 경고 및 졸음·눈 감김·휴대전화로 남은 주의분산에는 적용하지 않습니다.

## 카메라가 없거나 작동하지 않을 때

미장착, 고장, 잘못된 출력 또는 데이터 끊김은 자동으로 버튼·페달·핸들 조작 기반 감시로 전환됩니다. 원인을 미장착으로 확정하는 기능은 아니며, 별도의 장착 설정은 없습니다. 카메라 DM 데이터가 정상으로 2초간 유지되면 카메라 감시로 복귀합니다.

| 모드 | 조작이 없는 동안의 단계별 기준 | 조건 |
|---|---|---|
| 0: 기본 | 5 / 15 / 25초 | 콤마 조작 기반 감시의 기본 시간 |
| 1: 실험 | 10 / 30 / 50초 | 기본의 2배, 주변 정보가 정상일 때 |
| 1: 추가 완화 | 최대 12 / 36 / 60초 | 아래 조건에 따라 최대 2.4배 |

실제 경고 시점에는 저속 예외, 조작에 의한 회복과 현재 경고 단계가 반영됩니다. 페달 또는 인정되는 속도 버튼 조작 후 15초 동안 배율에 0.2를 더하며, 관측 범위가 확보된 빈 직선도로에서 안정 상태가 10초간 유지되면 0.2를 더합니다. 이 조건이 사라지면 적용 시간도 줄어들 수 있습니다.

빈 도로 추가 완화는 지원되는 현대·기아 코너레이더가 켜져 있고 레이더·도로 모델이 정상인 경우에만 가능합니다. 전방과 좌우에 유효한 관측 대상이 없고, 차선 신뢰도·조향각·회전율·가속도 조건이 맞아야 합니다. 감지 목록이 비었다는 이유만으로 센서 사각지대까지 비어 있다고 판단하지 않습니다. 주변 정보가 없거나 오래되면 기본 기준을 적용합니다.

카메라 사용 불가 상태가 지속되면 “운전자 카메라 사용 불가 / 버튼·페달·핸들 조작으로 감시 중”을 표시합니다. 감시 방식이 바뀌어도 감시 진행 상태와 주황색·최고 단계 경고를 초기화하지 않습니다. 카메라 없는 감시는 졸음이나 전방주시를 직접 확인할 수 없습니다.

## 차량 감지와 조작 인정

전방·좌우 차로에서 새로 움직이는 차량이 감지되면 1번도 10초 동안 기본 기준을 사용합니다. 같은 차량의 지속 관측과 짧은 감지 깜빡임은 매번 10초를 다시 시작하지 않으며, 새로운 차량이 들어오면 다시 시작할 수 있습니다. 시간이 끝나도 이미 쌓인 무응답 시간이나 강한 경고를 지우지 않습니다.

페달·핸들은 누르기 시작한 변화, 차량 버튼은 새 누름을 인정합니다. 계속 누르고 있는 상태나 자동 속도 변경은 새로운 반응으로 세지 않습니다. 순정 ACC에서 자동 속도 버튼 송신을 사용하는 구성은 물리적 속도 버튼과 송신 반사를 구분하기 어려워 해당 차량 속도 버튼의 감시 회복을 제외합니다. 페달·핸들과 BT 입력은 계속 사용할 수 있습니다.

등록·활성화된 BT 리모컨의 실제 클릭 또는 처음 발생한 길게 누르기를 인정하며, 주행 기능이 배정되지 않은 버튼도 포함합니다. 연결 유지, 학습 화면의 시험 입력, 오래된 이벤트, 길게 누르기의 자동 반복은 회복에 사용하지 않습니다. 버튼 조작은 반응했다는 근거이며 졸음이 해소됐다는 보증은 아닙니다.

## 경고 이후와 웹 영상

최고 단계 경고의 기존 감속 요청과 재사용 제한을 유지합니다. 이 변경은 새로운 긴급 정지나 정차 보장 기능을 제공하지 않으며, 순정 ACC 차량에서는 같은 감속을 보장할 수 없습니다. DM 시간 초과만으로 새롭게 조향을 즉시 해제하는 처리를 추가하지 않습니다. 도로 카메라·차량 통신·DM 프로세스 자체의 고장 처리는 별도로 유지합니다.

웹 도로 영상은 독립 설정 `CarrotVisionEnabled`로 켭니다. 기존 `DisableDM=2`의 영상 기능은 최초 전환 시 이 설정으로 옮기며, 운전자 감시는 기본 모드로 시작합니다. USB 계기판 사용 중에는 Carrot Vision을 사용할 수 없습니다.
