# 운전자 감시

`DriverMonitoringMode`는 `0: 기본`이 기본값이며 `1: 실험 모드`를 따로 선택합니다. 변경 후 기기를 재부팅하세요. 기존 `DisableDM` 값은 실험 모드로 승계하지 않습니다.

> [!CAUTION]
> 실험 모드는 법규에 위배될 수 있으므로 통제된 시험 환경에서 실험 목적으로만 사용하세요. 아래 시간은 구현된 설정값이며 법정 허용시간이나 국가별 인증을 의미하지 않습니다. 카메라 없는 0번도 콤마 순정과 다른 시간 기준을 사용합니다.

## 네 가지 동작

| 카메라·모드 | 단계별 경고 기준 | 조작과 전방주시 |
|---|---|---|
| 카메라 정상 · 0 | 콤마 순정: 카메라 기준 5 / 8 / 13초 | 순정 회복·초기화 조건 유지 |
| 카메라 정상 · 1 | 10 / 16 / 26초; 빈 도로 조건에서 20 / 32 / 52초 | 새 조작으로 초기화 후 45/90초 유예; 뚜렷한 전방주시 2초로 초기화 |
| 카메라 사용 불가 · 0 | 15 / 30 / 45초 | 유효한 새 조작으로 초기화 |
| 카메라 사용 불가 · 1 | 15 / 30 / 45초; 빈 도로 조건에서 30 / 60 / 90초 | 유효한 새 조작으로 초기화 |

시간은 정상 상태에서 회복 없이 계속 주의분산 또는 무조작이 누적되는 경우의 시작 기준입니다. 각 숫자를 차례로 더하지 않습니다. 약 10km/h 미만의 순정 저속 예외, 인식 필터, 기존 누적 상태에 따라 실제 경고 시점은 달라집니다. 최고 단계 경고와 재사용 제한은 아래 초기화 대상에서 제외합니다.

## 카메라를 사용할 수 있을 때

0번은 콤마의 얼굴·고개 방향·눈 감김·졸음·휴대전화 판단, 입력 처리 및 경고 기준을 유지합니다. 정상 전방주시 중에는 시간이 회복되므로 무조작만으로 주기적으로 경고하지 않습니다. 차량·BT 버튼을 새 회복 신호로 추가하지 않습니다.

1번은 카메라 경고 시간을 기본 2배, 빈 도로 조건에서는 4배로 적용하고 고개 방향 허용 폭을 20% 늘립니다. 눈 감김·졸음·휴대전화의 검출 확률 기준은 유지하지만, 해당 감지의 경고 시간도 늘어납니다. 주황색·최고 경고 중에는 고개 방향 허용 폭을 추가로 넓히지 않습니다.

유효한 새 운전자 조작 또는 BT 버튼은 일반·주황색 단계에서 감시 상태를 초기화합니다. 그 후 **45초, 빈 도로 조건에서는 90초 동안 카메라 경고를 유예**하며, 유예가 끝난 뒤 카메라 감시시간을 세기 시작합니다. 예를 들어 조건이 계속 같고 조작 직후부터 주의분산이 이어지면 첫 경고는 약 45+10=55초, 빈 도로에서는 약 90+20=110초 후가 될 수 있습니다. 최고 경고 기준도 각각 약 71초와 142초까지 늦어질 수 있습니다.

> [!WARNING]
> 이 유예는 졸음·눈 감김·휴대전화 경고도 지연합니다. 조작했다는 사실은 깨어 있거나 전방을 보고 있다는 보증이 아닙니다. 유예 중에도 카메라 검출은 계속하지만 경고시간은 누적하지 않습니다.

뚜렷한 전방주시 지표가 0.9 이상으로 2초 유지되면 감시 상태를 초기화합니다. 얼굴·양쪽 눈의 신뢰도, 고개 방향, 눈 감김·졸음·휴대전화·선글라스 정보를 조합하며, 각성을 보증하는 확률은 아닙니다. 전방주시 초기화는 조작 유예를 새로 시작하지 않습니다. 기존 최대 2초 회복과 1.5배 회복 속도 방식은 사용하지 않습니다.

카메라 데이터는 정상이지만 얼굴을 못 보거나 판단이 불확실한 경우에는 순정 내부의 조작 감시 전환이 남아 있습니다. 0번은 순정 기준을 유지하고, 1번의 조작 감시 기준은 카메라 없는 1번과 같은 15/30/45초 또는 30/60/90초입니다.

## 카메라가 없거나 작동하지 않을 때

미장착·고장·잘못된 출력·데이터 끊김은 자동으로 조작 기반 감시로 전환합니다. 원인을 미장착으로 확정하는 기능이나 별도의 장착 설정은 없습니다. 정상 카메라 DM 데이터가 2초간 이어지면 카메라 감시로 복귀하며 전환만으로 감시 진행 상태를 초기화하지 않습니다.

0번과 1번 모두 기본은 15/30/45초입니다. 1번은 빈 도로 조건에서만 30/60/90초가 됩니다. 최고 경고 전 유효한 새 조작이 들어오면 전체 감시시간을 초기화합니다. 예를 들어 기본 조건에서 무조작 20초 후 BT 버튼을 누르면 다시 약 15초 뒤부터 1단계 경고 기준이 됩니다.

카메라가 없으면 전방주시·눈 감김·졸음을 직접 확인할 수 없으므로 전방주시 초기화는 적용할 수 없습니다. 이 상태가 지속되면 카메라 사용 불가 및 조작 기반 감시 안내를 표시합니다. 도로 카메라·차량 통신·DM 프로세스 자체의 고장 처리는 별도로 유지합니다.

## 빈 도로와 새 차량

추가 2배는 지원되는 현대·기아 코너레이더가 켜져 있고 레이더·도로 모델이 정상이며, 관측 범위에 이동 차량이 없는 안정적인 직선도로 상태가 10초간 유지될 때만 적용합니다. 차선 신뢰도·조향각·회전율·가속도와 방향지시등 상태도 확인합니다. 정보가 없거나 오래되면 추가 배율을 적용하지 않습니다.

이동 차량은 전후 방향 -10~150m, 경로 좌우 6m 이내에서 **지면 기준 속도 크기 2m/s(약 7.2km/h) 이상**인 관측을 사용합니다. 같은 속도로 달리는 앞차도 포함하며 정지·저속 관측은 이 판정에서 제외합니다. 따라서 이 조건은 정지 차량이나 사각지대까지 비었다는 뜻이 아닙니다. 단발성 관측도 즉시 빈 도로 배율을 해제하고, 약 0.2초 연속 확인되면 20초 유지 구간을 시작합니다. 이는 레이더 노이즈를 완전히 제거하는 기능이 아닙니다.

새 이동 차량이 확인되면 **20초 동안 추가 배율을 해제**합니다. 카메라 없는 1번은 15/30/45초, 카메라 있는 1번은 10/16/26초 및 최대 45초 조작 유예로 돌아갑니다. 동일 차량이 계속 보이는 것만으로 20초를 반복 시작하지 않지만, 그 차량이 보이는 동안에는 빈 도로 조건을 만족하지 않습니다.

기존 경과시간은 유지합니다. 90초 유예 중 50초가 지났을 때 차량이 나타나면 45초 기준을 이미 넘었으므로 유예가 종료되고 카메라 감시시간이 시작됩니다. 한 번 끝난 유예는 도로가 다시 비었다는 이유로 되살리지 않습니다. 시간이 늘어나는 것만으로 기존 주황색·최고 경고를 지우지 않습니다.

## 어떤 조작을 인정하는가

아이오닉 5 PE의 원본 핸들 터치 신호를 지원합니다. 가장 낮은 접촉 단계인 `TOUCH_DETECT=1`부터 인정하며, `TOUCH1/2`의 작은 흔들림만으로 접촉을 추정하지 않습니다. 미지원 차량에는 자동으로 적용하지 않습니다.

카메라 사용 불가 시 0·1번 모두 유효한 접촉이 유지되는 동안 조작 감시시간을 초기화합니다. 손을 떼거나 신호가 0.25초 넘게 끊기면 기존 감시시간 누적을 재개합니다. 카메라 정상·1번에서는 유효한 손 뗌 뒤 새로 잡은 순간만 조작 유예를 시작하고, 계속 잡거나 통신이 복구된 것만으로 유예를 반복하지 않습니다. 카메라 정상·0번은 순정 그대로이며, 터치는 전방주시나 각성을 증명하지 않습니다. 최고 경고와 재사용 제한은 터치로 해제하지 않습니다.

페달·핸들은 차량이 보고한 운전자 입력의 시작, 차량 버튼은 지원되는 크루즈·차간거리·조향보조 버튼의 새 누름을 인정합니다. 새 DM2 입력 처리는 계속 누르고 있는 상태, 자동 속도 변화, BT 자동 반복을 새 조작으로 세지 않습니다. 카메라 있는 0번의 순정 핸들·가속 입력 처리는 그대로입니다.

순정 ACC 자동 속도 버튼 송신을 사용하는 구성에서는 실제 속도 버튼과 송신 반사를 구분하기 어려워 해당 차량 속도 버튼은 제외합니다. 페달·핸들과 BT 입력은 계속 사용할 수 있습니다. 등록·활성화된 BT 리모컨의 실제 클릭 또는 최초 길게 누르기를 인정하며, 주행 기능이 배정되지 않은 버튼도 포함합니다. 연결 유지, 학습용 시험 입력과 오래된 이벤트는 제외합니다.

## 최고 경고와 웹 영상

최고 단계 경고 이후에는 조작·전방주시·도로 조건 변경만으로 해제하지 않습니다. 기존 감속 요청과 재사용 제한을 유지합니다. 이 변경은 새 긴급 정지나 정차 보장 기능을 제공하지 않으며, 순정 ACC 차량에서 같은 감속을 보장하지 않습니다.

웹 도로 영상은 독립 설정 `CarrotVisionEnabled`로 켭니다. 기존 `DisableDM=2`의 영상 기능만 최초 전환 시 옮기며 감시는 기본 모드로 시작합니다. USB 계기판 사용 중에는 Carrot Vision을 사용할 수 없습니다.
