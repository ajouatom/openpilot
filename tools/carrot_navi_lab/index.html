클러스터 연결 대기
실행 중인 클러스터의 실제 TMAP 미디어 스트림 연결 대기 중

1. 운영 fMP4 → video 직접 표시

WAIT
운영 muxer + 운영 worker + MSE

2. 현재 분할: fMP4 video → canvas

WAIT
운영 muxer + 운영 worker + MSE + drawImage

3. 실제 H.264 → WebCodecs canvas

WAIT
앱 Annex-B H.264를 브라우저에서 직접 디코딩

4. 실제 H.264 → 서버 JPEG canvas

WAIT
앱 H.264를 PC PyAV로 디코딩한 기준 화면
네 화면은 모두 같은 실제 TMAP 프레임을 사용합니다. 4번만 보이면 브라우저 디코더 문제, 1번만 보이면 video→canvas 문제, 3·4번만 보이면 fMP4/MSE 문제로 바로 좁힐 수 있습니다.
