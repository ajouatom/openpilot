1 · 기존 설치파일에 패치 풀기

Extract into your existing installer

패치 ZIP 안의 내용을 기존 CarrotJetson 폴더 안에 풀어 주세요. support 폴더는 합치고 같은 이름의 파일은 교체하세요.

Extract the patch ZIP contents inside your existing CarrotJetson folder. Merge the support folders and replace matching files. The original installer supplies Python; no separate installation is needed.

처음 설치하는 매체는 기존 01 → 02를 실행하세요. 이미 R2 이미지를 기록한 매체는 다시 기록하지 않아도 됩니다.

For new media, run the existing steps 01 then 02. Media that already contains the R2 image does not need rewriting. Step 02 erases the selected medium: back it up first.

NVMe는 NVMe용 USB 외장 케이스로 PC에 연결하세요.

Connect NVMe to the PC using a USB NVMe enclosure. Internal PC SSDs are intentionally excluded.

2 · 공용 패치 실행

Apply the common patch

03_SD_SSD공용패치.cmd를 더블클릭하세요.

Double-click 03_SD_SSD공용패치.cmd.

관리자 권한 예 → 대상 디스크의 번호 입력 → 확인 후 PATCH 입력

Choose Yes at the administrator prompt, enter the target disk number, then type PATCH to confirm. Any other confirmation cancels.

검사·패치·기록 확인은 자동입니다. 완료 표시가 나올 때까지 기다리세요.

Verification, patching and readback are automatic. Wait for completion. Do not unplug, close the window or turn off the PC. If interrupted, reconnect and run the same patch again; do not boot a partly patched device.

3 · 전원을 끄고 장착

Install only with power disconnected

PC에서 안전하게 제거한 뒤, Jetson을 정상 종료하고 전원을 완전히 분리하세요. 사용할 SD 또는 NVMe를 장착한 다음 전원을 연결하세요.

Safely eject from the PC. Shut down Jetson and fully disconnect power before inserting SD or installing NVMe. Reconnect power afterwards.

같은 이미지를 기록한 SD와 NVMe를 동시에 꽂지 마세요.

Install only one copy of the image. Cloned SD and NVMe have identical partition identities and must not be connected together.

첫 시험은 안전하게 정차하고 주행 보조를 해제한 상태에서 부팅·Wi-Fi·모델 연결을 확인하세요.

Test boot, Wi-Fi and model connection while safely parked with driver assistance disengaged. This patch does not update QSPI firmware; compatible JetPack 6 / L4T 36 firmware is still required.

나중에 02로 원본 이미지를 다시 기록했다면 03 패치도 다시 실행하세요.

After any later rewrite of the original image with step 02, run the patch again. SSD capacity beyond the existing image layout is not automatically expanded.
