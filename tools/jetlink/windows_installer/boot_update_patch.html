USB 저장장치에 패치하고
다시 장착하세요.

Patch your existing boot storage once, then reinstall it.

이후 필요한 Jetson 업데이트는 시동 후 자동으로 진행됩니다.

After migration, required Jetson updates run automatically at startup.

사용 전 확인

Before you begin

기존 R2 설치 또는 SD/NVMe v2 패치 적용본용 시험판입니다. PC 검사는 완료했으나 실제 저장장치 기록·Jetson 부팅은 아직 확인 전입니다.

Preview for existing R2 or SD/NVMe v2 installations. Desktop checks passed; physical media patching and Jetson boot remain unverified.

다른 설치는 검사 후 중단합니다. 포맷하거나 새 이미지를 설치하지 마세요. 중요한 내용은 먼저 백업하세요.

Other installations are rejected. Do not format or reinstall an image. Back up important data first.

1 · 전원을 끄고 PC에 연결

Power off and connect to your PC

Jetson을 정상 종료하고 전원을 완전히 분리한 뒤 부팅용 저장장치를 빼세요. USB 케이스·리더를 통해 Windows PC에 연결하세요.

Shut down Jetson and disconnect power completely before removing its boot storage. Connect it to Windows through a USB enclosure or reader.

Windows가 포맷하겠냐고 물으면 취소하세요.

Cancel any Windows prompt to format the drive.

2 · 패치 파일 하나 실행

Run the patch

ZIP을 PC에 모두 풀고 Jetson_자동업데이트패치.cmd를 실행하세요. 기존 설치 ZIP이나 별도 Python은 필요 없습니다.

Extract the entire ZIP to your PC and run Jetson_자동업데이트패치.cmd. The original installer and a separate Python installation are not needed.

Enter → 관리자 권한 예 → 대상 디스크 번호 → PATCH 순서로 진행하세요.

Press Enter, allow administrator access, select the target disk number, then type PATCH.

약 5~20분 동안 검사·패치·기록 확인이 진행됩니다. 느린 저장장치는 더 걸릴 수 있습니다. 완료 표시 전에는 분리하거나 창을 닫지 마세요.

Allow about 5–20 minutes for checks, patching and readback; slow storage may take longer. Do not unplug or close the window before completion.

3 · 다시 장착하고 시동

Reinstall and start

PC에서 안전하게 제거한 뒤, 전원이 분리된 Jetson에 다시 장착하세요. C4도 최신 버전으로 업데이트하고 USB와 인터넷을 연결하세요.

Safely eject, then reinstall with Jetson power disconnected. Update C4 to the latest version and connect USB and Internet.

첫 확인은 정차 상태에서 하세요. 필요한 업데이트가 있으면 Jetson 실행을 기다리게 하고 자동으로 다운로드·검증·적용합니다. 인터넷이 없으면 연결될 때까지 기다립니다.

Verify the first startup while parked. Required updates hold Jetson execution until download, verification and activation finish. Without Internet, it waits for connectivity.

Carrot Web의 최초 업데이트 대기나 SSH 접속은 필요 없습니다. PC의 완료 표시는 패치 기록 확인이며, Jetson 프로그램 적용 완료는 다음 부팅에서 확인합니다.

No Web first-update wait or SSH access is needed. PC completion confirms the patch write; runtime activation takes place on the next Jetson boot.

중간에 끊겼다면

If interrupted

부분 적용 상태로 부팅하지 말고 같은 패치를 다시 실행해 완료를 확인하세요. 실패가 반복되면 포맷하지 말고 패치 폴더의 logs를 확인하세요.

Do not boot a partly patched device. Rerun the same patch and wait for success. If it keeps failing, do not format; inspect the logs folder.
