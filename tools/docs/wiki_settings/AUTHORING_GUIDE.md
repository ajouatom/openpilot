# Carrot 설정 Wiki 작성 가이드

설정 설명은 짧고 객관적으로 작성한다. 모든 설정은 `개요`, `동작`, `사용`, `참고` 네 구역만 사용하며 내용이 없는 선택 구역은 만들지 않는다.

## 페이지 원칙

- 설정 하나는 언어별로 독립된 Markdown 파일 하나를 사용한다.
- 파일명과 페이지 제목은 `carrot_settings.json`에서 Carrot Web이 실제로 표시하는
  언어별 제목을 사용한다. 예: `KO-상시-조향.md`, `EN-Always-Lateral.md`,
  `ZH-全时横向控制.md`.
- 파일명은 `{대문자 언어 코드}-{현재 언어의 표시 제목}.md`를 기본으로 한다.
  Unicode는 NFKC로 정규화하고 공백은 `-`로 바꾸며, 파일명과 URL에 안전하지 않은
  문자는 `-`로 바꾼다. 페이지 안의 제목은 원래 표시 제목을 바꾸지 않는다.
- 파일명이 바뀌어도 설정은 `AlwaysLateral` 같은 파라미터로 식별한다. 제목이
  바뀌면 생성기가 페이지를 이동하고 같은 파라미터의 `CARROT:MANUAL` 내용을
  그대로 보존한다.
- 한 파일에는 `CARROT:SETTING` 블록이 정확히 하나만 있어야 한다.
- 저장소에서 작업하는 AI는 이 문서를 먼저 읽고, Wiki만 받은 AI는 각 페이지 상단의
  `CARROT:AUTHORING` 링크로 이 규격을 확인한다.
- 사람과 AI는 `CARROT:MANUAL` 영역만 작성한다. `CARROT:AUTO` 영역과 모든 마커는
  생성기가 관리한다.

## 기본 구조

```markdown
<!-- CARROT:SETTING:BEGIN AutoNaviSpeedCtrlEnd -->
<a id="AutoNaviSpeedCtrlEnd"></a>

## 과속카메라 감속 완료 시간

`AutoNaviSpeedCtrlEnd`

과속카메라에 접근할 때 목표속도에 도달하는 시점을 조정합니다.

<!-- CARROT:AUTO:BEGIN AutoNaviSpeedCtrlEnd -->
<!-- CARROT:SECTION:BEGIN OVERVIEW -->
- **종류:** 숫자
- **기본값:** `6초`
- **범위:** `3~20초`
- **메뉴:** 설정 > 주행 제어 > 속도·감속 > 과속카메라
<!-- CARROT:SECTION:END OVERVIEW -->
<!-- CARROT:AUTO:END AutoNaviSpeedCtrlEnd -->

<!-- CARROT:MANUAL:BEGIN AutoNaviSpeedCtrlEnd -->
<!-- CARROT:REVIEW reviewed-for="자동 영역의 semantic 해시" reviewed-at="2026-07-23T00:00:00Z" -->
<!-- CARROT:SECTION:BEGIN BEHAVIOR -->
### 동작

- **높이면:** 더 일찍 감속을 완료하여 낮은 속도를 오래 유지합니다.
- **낮추면:** 카메라에 더 가까워진 뒤 감속을 완료합니다.
<!-- CARROT:SECTION:END BEHAVIOR -->

<!-- CARROT:SECTION:BEGIN USAGE -->
### 사용

감속이 너무 늦거나 지나치게 일찍 끝난다고 느낄 때 조금씩 조정합니다. 변경 후 같은 종류의 감속 구간에서 동작을 확인합니다.
<!-- CARROT:SECTION:END USAGE -->

<!-- CARROT:SECTION:BEGIN REFERENCE -->
### 참고

<!-- CARROT:NOTICE level="NOTE" -->
> [!NOTE]
> 설정값은 카메라 통과 후 시간이 아니라 감속 완료 지점을 계산하는 시간 기준입니다.
<!-- CARROT:NOTICE:END -->
<!-- CARROT:SECTION:END REFERENCE -->
<!-- CARROT:MANUAL:END AutoNaviSpeedCtrlEnd -->

<!-- CARROT:SETTING:END AutoNaviSpeedCtrlEnd -->
```

## 자동 정보 검토 상태

- 생성기는 자동 영역의 `CARROT:AUTO:SOURCE`에 전체 사실 해시와 의미 관련 사실 해시를 기록한다.
- 수동 설명을 확인한 작성자는 `CARROT:REVIEW reviewed-for`에 현재 `semantic` 해시를 그대로 기록하고 `reviewed-at`에 시간대가 포함된 ISO 8601 시각을 기록한다.
- 제어 종류·설명·기본값·범위·변경 단위·표시 단위·선택지·위험 수준이 바뀌면 기존 검토가 자동으로 `needs_review`가 된다.
- 제목이나 메뉴 위치만 바뀐 경우에는 의미 해시가 유지되므로 수동 설명을 다시 쓰지 않는다.
- 검토 마커를 포함한 `MANUAL` 영역은 생성기가 수정하지 않는다. 설정이 다른 그룹으로 이동해도 파라미터 이름으로 찾아 그대로 옮긴다.
- 빈 수동 영역과 검토 마커가 없는 기존 항목은 `needs_review`로 처리한다.

## 네 구역

| 구역 | 내용 | 표시 |
|---|---|---|
| `OVERVIEW` · 개요 | 종류·기본값·범위·단위·선택지·메뉴 | 항상 |
| `BEHAVIOR` · 동작 | 값에 따른 변화·조건·적용 범위 | 내용이 있을 때 |
| `USAGE` · 사용 | 조정·적용·확인·복구·재시작 | 내용이 있을 때 |
| `REFERENCE` · 참고 | 오해 방지·예시·미디어·관련 가이드 | 내용이 있을 때 |

차종·하드웨어·지역·모드는 `동작`의 적용 범위로 작성한다. 사진·영상·도식은 `참고`에 둔다. 알림은 별도 구역을 만들지 않고 관련 구역에 붙인다.

## 설명 밀도

- 설정명 다음의 요약은 목적을 설명하는 한 문장으로 작성한다.
- 각 구역은 핵심 설명 1~2문장으로 시작하고 필요한 사실만 목록으로 덧붙인다.
- `동작`은 실제 변화, `사용`은 조정 시점과 확인 방법, `참고`는 오해하기 쉬운 내용만 적는다.
- 한 문단은 기본 2문장, 방향별 변화는 1줄로 제한한다.
- 기본값·범위·단위는 수동 설명에 반복하지 않는다.
- 검증되지 않은 권장값, 추측, 배경 설명, 홍보 표현을 넣지 않는다.

## 설정 종류별 필수 내용

| 종류 | 개요 | 동작 |
|---|---|---|
| 토글 | 기본 상태 | 켜짐·꺼짐 차이 |
| 선택 | 기본값·전체 선택지 | 선택지별 차이 |
| 숫자 | 기본값·최소·최대·단위·변경 단위 | 높임·낮춤의 변화 |
| 실행 | 확인·취소 가능 여부 | 실행 결과 |
| 목록·프로필 | 항목 형식·초기값 | 항목 관계·적용 범위 |
| 정보·진단 | 출력 형식·표시 위치 | 주행 동작에 미치는 영향 |

`0`, `-1`, 빈 값에 특별한 의미가 있으면 `개요`에 명시한다. 화면 표시 단위와 저장 단위가 다르면 화면 단위를 우선하고 변환 설명은 `참고`에 둔다.

## 허용 Markdown

- 제목 `#`~`####`
- 문단, 굵게, 인라인 코드
- 글머리 목록과 번호 절차
- 목적이 드러나는 링크
- 최대 3열의 단순 표
- GitHub Alert
- 이미지, 영상 링크, 제한적인 Mermaid
- 긴 기술 설명의 `<details>`
- `<!-- CARROT:* -->` 자동화 마커

다음 항목은 금지한다.

- `<style>`, `<script>`, `<iframe>`과 이벤트 속성
- 임의 HTML 레이아웃과 고정 폭
- 인라인 색상·폰트·간격 지정
- 장식용 이모지와 색상만을 사용한 구분
- Wiki에서만 의미가 있는 사용자 정의 문법
- 같은 정보의 반복

## 알림

| 등급 | 용도 |
|---|---|
| `NOTE` | 오해하기 쉬운 의미·단위 보충 |
| `TIP` | 선택적인 확인 팁 |
| `IMPORTANT` | 필수 조건·재시작·지원 상태 |
| `WARNING` | 기능 이상 가능성 |
| `CAUTION` | 안전·차량 동작·데이터 손실 위험 |

- 설정 하나의 알림은 최대 2개로 제한한다.
- 알림을 연속으로 배치하지 않는다.
- 같은 내용을 합칠 수 있으면 가장 높은 등급 하나로 합친다.

## 언어

- 파일은 UTF-8과 LF 줄바꿈을 사용한다.
- 한국어·영어·중국어의 파일명, 페이지 제목, 목록 이름과 메뉴 계층은
  Carrot Web이 해당 언어에서 사용하는 현재 카탈로그와 일치해야 한다.
- `SETTING`, `SECTION`, 콘텐츠 토큰, 파라미터 이름은 번역하지 않는다.
- 언어 코드는 BCP 47 형식을 사용한다.
- 문장 조각을 결합하지 않고 언어별 완전한 문장으로 작성한다.
- 자리표시자는 `{value}`, `{unit}`, `{setting}`처럼 이름을 사용한다.
- 숫자·선택지 코드·링크 대상은 모든 언어에서 같아야 한다.
- 한국어와 영어 페이지의 설정 순서·구역·선택지·자리표시자는 일치해야 한다.

## 미디어

- 이미지에는 의미를 설명하는 대체 문구와 본문 설명을 제공한다.
- 영상에는 길이와 확인 구간을 적고 자막·대본·동등한 설명 중 하나를 제공한다.
- 번호판·얼굴·주소·토큰·장치 식별자는 제거한다.
- 자동재생과 점멸 콘텐츠를 사용하지 않는다.
- 미디어가 없어도 설정의 핵심 내용을 이해할 수 있어야 한다.

## 삭제

`carrot-wip`의 현재 `carrot_settings.json`에 없는 설정은 생성 문서와 인덱스에서 삭제한다. 삭제 설명을 별도 페이지에 보관하지 않는다.
