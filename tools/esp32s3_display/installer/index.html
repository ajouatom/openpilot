펌웨어 1.1.0 · N16R8 전용 · 2026-10-15

펌웨어·설명서 ZIP 받기 파일 검증값

1. 준비할 제품

제품확인할 내용
ESP32-S3 N16R8 보드Flash 16MB / Octal PSRAM 8MB, USB-C 두 개, UART·USB 표시가 있는 DevKitC-1 형태. 안테나가 붙어 있는 보드를 권장합니다.
TURZX 9.2인치 USB 화면1920×462, USB ID 1cbe:0092. 이 조합으로 시험했습니다.
외부 전원 USB 허브본체 연결용 케이블과 데이터 포트, 별도의 전원 입력이 필요합니다. 허브 호환성은 제품마다 다릅니다.
케이블·전원데이터 지원 USB 케이블, 화면과 허브의 요구 전력을 충족하는 USB 전원 장치.

ESP32, S2, C3, N8R2 또는 PSRAM이 없는 보드는 이 파일의 설치 대상이 아닙니다. USB-C 영상 입력(DP Alt Mode) 모니터나 HDMI 화면은 지원하지 않습니다. 외장 안테나형 보드는 별도 안테나가 필요하며 이번 검증 대상이 아닙니다.

2. 두 USB 포트를 구분해 연결

좌우 위치보다 보드에 인쇄된 UART / USB 글자를 확인하세요. UART는 PC에, USB는 허브에 연결합니다. 화면은 허브의 데이터 포트, 충전기는 허브의 전원 입력에 연결합니다.

시험한 보드는 S3의 USB 포트에서 화면용 전원이 나오지 않아 외부 전원 허브가 필요했습니다. 전원만 연결되면 제조사 로고가 보일 수 있습니다. CARROT 영상이 나오는 것은 별도 등록을 마친 뒤입니다. 정상 설치 후 대기 중에는 화면이 꺼지는 것이 정상입니다.

3. PC에서 펌웨어 설치

  1. PC의 Chrome 또는 Edge로 이 HTTPS 페이지를 엽니다. 폰 브라우저에서 설치하지 마세요.
  2. S3의 UART 포트를 PC에 연결합니다. 다른 시리얼 모니터·설치 프로그램을 닫습니다.
  3. 아래에서 설치 방법을 선택하고 버튼을 누릅니다. 포트 목록에서 CP210x / USB Serial에 해당하는 S3를 선택하세요.
  4. 완료 메시지를 기다립니다. 설치 후에는 USB 연결이 자동으로 해제되고 S3가 재시작합니다.

설치 도구 준비 중…

설치 진행 기록


전체 지우기를 하지 않습니다. 업데이트는 기존 파티션을 확인한 뒤 앱만 교체하고, 등록 저장 영역이 그대로인지 검증합니다. 처음 설치는 해당 보드의 기존 프로그램을 CARROT으로 교체합니다. 다른 펌웨어에서 이전하는 경우는 새 보드와 동일한 절차를 적용하세요.


포트가 없거나 연결에 실패하면
충전 전용 케이블을 데이터 케이블로 교체하고 UART 포트를 확인합니다. Windows 장치 관리자에서 CP210x 드라이버가 없으면 Silicon Labs 공식 드라이버를 설치하세요. CH340 등 다른 UART 칩인 보드는 그 칩의 드라이버가 필요합니다.
자동 연결이 계속 실패하면 BOOT를 누른 채 RESET을 한 번 눌렀다 떼고, BOOT도 뗀 뒤 다시 설치합니다. 완료 후 RESET을 한 번 누르세요. 업데이트 중 실패하면 케이블을 확인하고 같은 설치를 다시 실행할 수 있습니다.


4. Wi-Fi와 C4 등록 — 두 가지 중 선택
C4에는 최신 carrot-nav 또는 carrot-wip가 필요합니다. 시동을 끈 상태에서도 등록할 수 있습니다. C4와 S3는 서로 통신할 수 있는 같은 네트워크에 있어야 합니다. 폰 핫스팟은 2.4GHz, 아이폰은 호환성 최대화를 사용하세요.


A. C4에 USB로 한 번 연결 — 권장
  1. C4를 사용할 Wi-Fi/폰 핫스팟에 먼저 연결합니다.
  2. S3의 UART 포트를 C4의 USB에 연결합니다. 화면용 허브는 S3의 USB 쪽에 둡니다.
  3. C4 웹 화면의 터미널 또는 SSH 터미널에서 아래 명령을 실행합니다.
cd /data/openpilot
python3 tools/esp32s3_display/provision.py --auto
한 개의 지원 UART가 연결돼 있으면 자동 선택합니다. 현재 Wi-Fi 이름·암호를 S3에 저장하고 C4 등록도 함께 마칩니다. 여러 포트가 있으면 명령에 표시되는 목록에서 S3를 확인한 뒤 --auto 대신 --port /dev/ttyUSB0처럼 지정하세요. 케이블을 꽂는 것만으로 등록되지는 않습니다.


B. 폰에서 Wi-Fi 설정
  1. 처음 설치한 보드는 설정 화면이 나옵니다. 이미 설정한 보드는 부팅이 끝난 뒤 BOOT를 3초간 눌러 설정을 엽니다. 전원을 넣을 때부터 누르면 다운로드 모드로 들어갑니다.
  2. 폰을 CARROT-HUD Wi-Fi에 연결합니다. 비밀번호는 12345678입니다.
  3. 주소창에 http://192.168.4.1을 입력합니다. 시간 초과가 나면 “인터넷 없이 연결 유지”를 선택하고 모바일 데이터를 잠깐 끕니다.
  4. 차에서 사용할 Wi-Fi 이름·비밀번호를 입력하고 Wi-Fi 저장을 누릅니다. 설정 창은 저장 약 15초 후 닫힙니다.
  5. 처음 C4에 등록하는 경우 처음 C4 연결: 등록 파일 받기를 누릅니다. 파일명은 매번 달라집니다. 이미 C4에 등록한 보드의 Wi-Fi만 바꾼다면 다운로드할 필요가 없습니다.
  6. 받은 JSON을 WinSCP/SFTP 등으로 C4의 /data/carrot-s3.json에 복사하고 아래 명령으로 등록합니다. 파일 전송이 익숙하지 않으면 위 A 방법을 사용하세요.
cd /data/openpilot
python3 tools/esp32s3_display/provision.py --import-pairing /data/carrot-s3.json
등록 JSON에는 해당 화면을 연결할 수 있는 키가 들어 있습니다. 다른 사람에게 보내거나 공개 게시판에 올리지 마세요. 폰이 핫스팟과 Wi-Fi 접속을 동시에 할 수 없으면 다른 폰으로 설정한 후 원래 폰의 핫스팟을 다시 켜세요.


5. 화면 사용과 다음 설정 변경
  1. C4 설정에서 외부 HUD (ClusterHud) → 9.2인치를 선택합니다.
  2. C4와 S3를 등록한 같은 Wi-Fi/핫스팟에 연결합니다. 차량에서 PC나 USB 테더링은 필요하지 않습니다.
  3. 기본적으로 시동을 켜면 HUD가 나오고 시동을 끄면 소등됩니다. 정차 중 시험은 ClusterHudDebug를 사용하고 시험 후 0으로 되돌리세요.
화면 밝기·방향·미러·카메라 등은 기존 HUD 설정을 사용합니다. Wi-Fi 화면은 기본 최대 15fps, eGPU 사용 시 최대 10fps이며 실제 속도는 화면 내용과 통신 상태에 따라 달라집니다. 화면을 바꾸는 일반 C4 업데이트마다 S3를 다시 설치할 필요는 없습니다.
SSID를 바꾸려면 부팅 후 BOOT 3초 → 폰 설정에서 저장하거나, 새 Wi-Fi에 연결된 C4에 UART를 연결하고 --auto 명령을 다시 실행합니다. 기존 C4 등록 키는 유지됩니다. 펌웨어 버그 수정은 이 페이지의 업데이트로 설치합니다. OTA 업데이트 기능은 없습니다.


문제가 있을 때
증상확인 순서
제조사 기본 화면만 보임S3 USB 포트·허브 본체 케이블·데이터 포트를 확인하세요. 허브 종류에 따라 USB 통신이 안 될 수 있습니다. 전원이 들어온 것만으로 통신 성공은 아닙니다.
설정 화면도 안 보임BOOT 3초 뒤 CARROT-HUD가 보이는지 확인합니다. Wi-Fi가 보이면 S3는 동작 중입니다. 화면/허브 연결을 점검하세요.
setup closed설정 시간이 끝났습니다. BOOT를 3초 눌러 다시 열고 CARROT-HUD로 재접속합니다.
등록했는데 화면이 꺼져 있음시동 OFF·Debug 0이면 정상입니다. 시동 ON에서도 나오지 않으면 C4 등록, 동일 네트워크, 핫스팟 기기 간 통신 허용을 확인하세요.
끊김·지연안테나 끝을 금속/허브에서 떨어뜨리고 2.4GHz 신호를 확인합니다. 다른 핫스팟과 비교합니다. 공유기 채널·혼잡도에 따라 달라지며 폰의 정상 접속만으로 S3 링크를 판단할 수는 없습니다.
시동을 꺼도 화면이 켜짐Debug를 0으로 설정하고 C4와 S3를 모두 업데이트합니다. 펌웨어 1.1.0은 종료 명령 실패를 재시도하며 통신이 끊겨도 자체 소등합니다. 설정 안내 중에는 화면이 켜져 있습니다.
